- **惡意 URL**: `hxxps://31[.]57[.]216[.]121/aarch64`
- **標籤**: CoinMiner, elf, geofenced, redtail, ua-wget, USA

此 URL 用於散佈 RedTail 加密貨幣挖礦程式（aarch64/ARM64 架構版本）。RedTail 是一個針對 Linux 伺服器的挖礦惡意程式，具有地理圍欄功能（僅針對美國 IP）。同一 IP 提供多種架構版本（aarch64、i686、arm7、x86_64）。

## 防禦建議

建議將 IP `31.57.216.121` 加入防火牆封鎖清單。監控伺服器的異常 CPU 使用率及加密貨幣挖礦行為。
