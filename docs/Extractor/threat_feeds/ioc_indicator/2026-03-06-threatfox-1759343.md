## IoC 詳情

此網域 `vant-v8.trailvantage.in.net` 被識別為 ClearFake 惡意程式的酬載投遞基礎設施。ClearFake 是一種基於 JavaScript 的攻擊框架，透過偽造瀏覽器更新頁面誘導使用者下載惡意程式。該網域屬於 `trailvantage.in.net` 子網域群組，疑似由同一攻擊者批量註冊用於惡意活動。

## 防禦建議

建議將此 IoC 加入 DNS 封鎖清單及網路閘道過濾規則。同時封鎖整個 `trailvantage.in.net` 網域以防範同一攻擊基礎設施的其他子網域。
