## 威脅描述

此 IP 位址（158.94.208.168）被識別為惡意 Windows 可執行檔（.exe）的下載伺服器，關聯至 RustyStealer 資訊竊取器及 Amadey 惡意軟體載入器。標籤 `dropped-by-amadey` 顯示此 payload 由 Amadey 惡意軟體下載並執行，為多階段惡意軟體攻擊鏈的一部分。標籤 `fbf543` 為 payload 雜湊特徵識別碼。該 URL 於 2026-03-26 被通報，狀態仍為 online。

## 關聯分析

RustyStealer 為以 Rust 語言編寫的資訊竊取器，可竊取瀏覽器儲存的憑證、Session Cookie 及加密貨幣錢包資料。Amadey 為知名的惡意軟體下載器/載入器（loader），常被用來下載並執行各類第二階段 payload（如 RustyStealer）。此 URL 為 Amadey → RustyStealer 多階段攻擊鏈的第二階段下載端點。
