## 技術分析

- **惡意軟體**：Mozi — P2P DHT Botnet，主要感染路由器、NAS、IoT 裝置（MIPS 架構）
- **感染路徑**：透過 `bin.sh` 腳本下載 MIPS ELF 二進位（Mozi.a、Mozi.m 等變種）
- **感染 IP 地理分布**：主要集中於中國（125.x、110.x、42.x）、巴基斯坦（110.37.x）、東南亞
- **載荷特徵**：32-bit MIPS ELF，透過非標準高位端口傳播，符合 Mozi 傳播特徵
- **威脅評估**：Mozi 儘管 2023 年主要開發者被捕，但 botnet 活動仍在持續
