## 威脅描述

此 URL 為 ClearFake 惡意程式的 x64 載荷下載點,使用 breeze1falcon.coupons 網域與隨機子網域 c9t5q。隨機字串子網域為 ClearFake 攻擊活動的典型特徵,用於快速生成大量分發 URL 以規避封鎖。

該 URL 為 breeze1falcon.coupons 網域在短時間內的第三次報告,證實此網域為高優先級威脅指標。

## IoC 指標

| 類型 | 值 |
|------|-----|
| url | `hxxps://c9t5q.breeze1falcon[.]coupons/x64` |
| domain | `breeze1falcon.coupons` |

## 關聯分析

breeze1falcon.coupons 網域同時使用有意義詞彙(glacier)與隨機字串(c9t5q、br33ze-llnk)作為子網域,顯示攻擊者可能使用混合策略:有意義詞彙用於社交工程攻擊,隨機字串用於自動化分發。

建議實施自動化監控機制,偵測類似命名模式的新 .coupons TLD 網域註冊,並即時更新封鎖清單。
