Mozi 是目前最活躍的 IoT 殭屍網路之一，使用點對點架構和 DHT（分散式雜湊表）進行命令與控制。該殭屍網路利用多個已知的 IoT 設備漏洞和弱憑證進行傳播。MIPS 架構表明此樣本針對特定類型的嵌入式設備。建議網路管理者封鎖此 IP 並檢查 IoT 設備的安全性。
