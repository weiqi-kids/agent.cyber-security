## 威脅描述

此 URL 為 Mozi 殭屍網路的 Mozi.a 變種下載點,檔案名稱明確標示為「Mozi.a」,為該惡意程式家族的特定版本。標籤 ua-wget 表明此惡意程式使用 wget User-Agent 進行下載,為 IoT 惡意程式的典型傳播方式。

報告者 NDA0E 專注於 Mozi 殭屍網路追蹤,其報告的威脅指標具備高專業性。

## 關聯分析

檔案名稱「Mozi.a」明確揭露惡意程式身份,可能表明此為較早期的 Mozi 變種或攻擊者未進行檔案名稱混淆。使用非標準埠號 58550 為規避基礎防火牆規則的常見手法。

建議封鎖此 IP 與埠號組合,並在 IDS/IPS 規則中加入對「Mozi.a」檔案名稱模式的偵測。
