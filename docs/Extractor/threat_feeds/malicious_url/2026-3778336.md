## 威脅描述

此 URL 提供 Vidar 資訊竊取程式的密碼保護壓縮檔(密碼:lunex),託管於綠色能源組織網域。Vidar 能竊取瀏覽器憑證、加密貨幣錢包、2FA 權杖及系統資訊,為當前最活躍的資訊竊取惡意程式之一。

該檔案名稱「LunX.zip」與密碼「lunex」的命名一致性顯示攻擊者使用系統化的檔案命名策略,可能用於追蹤不同攻擊活動或受害者群組。

## 關聯分析

此惡意檔案託管於環保組織網域,與 ID 3778337 的健身房網域模式相同,證實攻擊者系統性入侵合法網站作為惡意程式分發管道。使用 `.org` TLD 可能進一步提高受害者信任度。

同一報告者(AmadeyHunter)在相近時間內報告多個類似的 Vidar 分發 URL,顯示此為協同攻擊活動的一部分。建議將相關網域加入監控清單並檢查 SSL 憑證異常。
