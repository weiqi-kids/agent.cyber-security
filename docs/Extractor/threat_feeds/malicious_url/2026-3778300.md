## 威脅描述

此 URL 為 ClearFake 惡意程式的 x64 載荷下載點,使用 matrix8piano.coupons 網域。此網域為本資料集中新發現的 ClearFake 基礎設施,與先前的 shadow6nectar、breeze1falcon 網域命名模式一致(「詞彙+數字+詞彙」)。

子網域 rnatr1x-vvay 使用數字替換字母與雙字母混淆技術,為規避自動化偵測的策略。

## 關聯分析

matrix8piano.coupons 網域在本資料集中至少出現 2 次(另見 ID 3778293、3778292),證實此為新啟用的 ClearFake 惡意程式分發基礎設施。該網域的命名模式顯示 ClearFake 攻擊者持續擴展其分發網路。

建議將 matrix8piano.coupons 加入封鎖清單,並監控使用類似命名模式的新 .coupons TLD 網域註冊。
