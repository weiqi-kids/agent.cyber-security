## 威脅描述

此 URL 提供 Vidar 資訊竊取程式的密碼保護壓縮檔(密碼:bluys),託管於 .lol TLD 網域。Vidar 為商業化資訊竊取惡意程式即服務(MaaS, Malware-as-a-Service),攻擊者可透過地下論壇租用並客製化攻擊目標。

網域 bolixtiol.lol 的路徑為 `/downloads`,暗示此網域可能專門用於惡意程式分發。`.lol` TLD 因註冊成本低且監管寬鬆,常被網路犯罪活動使用。

## 關聯分析

此為同一時段內第三個由 AmadeyHunter 報告的 Vidar 分發 URL,與 ID 3778337(cyrex)、3778336(lunex)形成系列攻擊活動。三個 URL 均使用密碼保護壓縮檔,但密碼各不相同,可能用於追蹤不同分發管道的感染效果。

Vidar 竊取程式通常與 Amadey 殭屍網路協同運作,後者作為初始感染載入程式。建議搜尋網路流量中是否存在 Amadey C2 通訊模式。
