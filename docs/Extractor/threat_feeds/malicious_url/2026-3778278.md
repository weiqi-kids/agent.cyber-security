## 威脅描述

此 URL 為 ClearFake 惡意程式的下載點,於報告時已離線。使用 jungle9orbit.coupons 網域與「outpost」子網域,子網域名稱為有意義的英文詞彙,可能用於提高 URL 的可信度。

該 URL 與 ID 3778284、3778275 共享相同的主網域,證實 jungle9orbit.coupons 為 ClearFake 攻擊活動使用的基礎設施網域。

## 關聯分析

jungle9orbit.coupons 網域在短時間內被報告多次不同的子網域,顯示攻擊者使用快速子網域輪替策略。多個 URL 均已離線,可能表明該網域已被安全社群識別並採取行動。

建議將整個 jungle9orbit.coupons 網域加入封鎖清單,防止未來可能啟用的新子網域。
