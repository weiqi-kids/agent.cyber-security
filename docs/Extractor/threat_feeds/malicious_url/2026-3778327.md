## 威脅描述

此 URL 為 ClearFake 惡意程式的 x64 架構載荷下載點,使用 shadow6nectar.coupons 基礎設施。子網域名稱「oracle」意圖模仿知名企業品牌,提高社交工程攻擊的成功率。

該 URL 與 ID 3778338、3778320 共享相同的主網域,證實 shadow6nectar.coupons 為持續活躍的 ClearFake 惡意程式分發網域。

## 關聯分析

使用「oracle」作為子網域名稱顯示攻擊者刻意模仿合法品牌以繞過使用者警覺。ClearFake 攻擊活動常結合品牌仿冒與偽造系統更新提示,形成多層次的社交工程攻擊鏈。

建議在 DNS 層級封鎖整個 shadow6nectar.coupons 網域,並實施品牌仿冒偵測機制監控類似的子網域註冊活動。
