## 威脅描述

此 URL 透過合法檔案分享服務 files.link 分發 TrustConnect 遠端存取木馬(RAT)。該服務使用 HTTP 302 重新導向,使追蹤與封鎖更加困難。TrustConnect RAT 能讓攻擊者完全控制受感染系統,包括檔案存取、鍵盤記錄、螢幕截圖及遠端指令執行。

使用合法檔案分享服務為現代惡意程式分發的常見策略,因這些服務通常不在企業封鎖清單中,且其 HTTPS 流量難以進行內容檢查。

## 關聯分析

TrustConnect RAT 常透過釣魚郵件或社交工程攻擊分發,偽裝成商業文件或軟體更新。該惡意程式支援持久化機制與反偵測技術,清除難度較高。

files.link 檔案 ID 為 UUID 格式,表明此為合法服務遭濫用。建議監控員工對未知檔案分享服務的存取,並實施應用程式白名單政策。
