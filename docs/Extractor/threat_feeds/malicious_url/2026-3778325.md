## 威脅描述

此 URL 為 Mirai 殭屍網路針對 ARM 架構的 ELF 惡意程式下載點,位於 IP 158.94.208.69。該 IP 同時託管多個架構的 Mirai 載荷(另見 ID 3778324 的 arm7 變種),為典型的 Mirai 多架構分發伺服器。

報告者 tolisec 專注於 IoT 威脅情報,其報告的 URL 通常具備高可信度。

## 關聯分析

此 IP 位址(158.94.208.69)在數分鐘內被報告兩次不同的 ARM 架構載荷(arm、arm7),證實此為活躍的 Mirai 分發基礎設施。ARM 架構廣泛應用於現代 IoT 設備,此 IP 構成的威脅範圍極廣。

建議封鎖此 IP 並檢查內部網路中所有 ARM 架構設備的韌體版本與網路隔離措施。
