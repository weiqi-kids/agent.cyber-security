## 威脅描述

此 URL 為 Mirai 殭屍網路的惡意程式下載點,提供 ELF 格式的二進位檔案(mpsl 變種)。Mirai 是一種專門感染 IoT 設備的殭屍網路惡意程式,於 2016 年因發動大規模 DDoS 攻擊而聲名狼藉,其原始碼洩露後衍生出大量變種持續活躍。

該 URL 位於 IP 位址 113.30.152.240,使用未加密的 HTTP 協定。標籤 `ua-wget` 表明此惡意程式使用 wget User-Agent 進行下載,為 Mirai 家族的典型傳播特徵。

## 關聯分析

Mirai 殭屍網路及其變種持續對全球 IoT 設備構成重大威脅。該惡意程式主要透過暴力破解 Telnet 預設密碼感染設備,並下載針對不同 CPU 架構(ARM、MIPS、x86 等)的二進位檔案。

此 URL 同時託管多個架構的惡意載荷(觀測到 mpsl、arm4、arm5、arm7、mips 等檔案),表明此為活躍的 Mirai 分發伺服器。建議封鎖此 IP 並檢查防火牆規則是否允許內部 IoT 設備對外連線。
