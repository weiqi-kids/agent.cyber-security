## 威脅描述

此 URL 為 Mirai 殭屍網路針對 ARM5 架構的 ELF 惡意程式下載點。ARM5 架構雖較老舊,但仍廣泛存在於遺留系統、低階嵌入式設備及工業控制設備中,這些設備往往已停止安全更新,成為理想的殭屍網路目標。

該 URL 與其他 Mirai 變種共享 113.30.152.240 基礎設施,證實此 IP 為持續活躍的惡意程式分發中心。
