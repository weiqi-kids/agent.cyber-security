## 威脅描述

此 URL 為 Mozi 殭屍網路的惡意程式下載點,提供針對 MIPS 架構 IoT 設備的 32-bit ELF 二進位檔案。Mozi 是一種基於 P2P 架構的 IoT 殭屍網路,主要透過 Telnet/SSH 弱密碼暴力破解及已知漏洞利用感染路由器、網路攝影機等物聯網設備。

該 URL 位於 IP 位址 61.52.159.154 的 60923 埠,使用未加密的 HTTP 協定。此類架構特徵為典型的 Mozi 惡意程式分發基礎設施,通常由遭感染的 IoT 設備作為分發節點。

## 關聯分析

Mozi 殭屍網路自 2019 年首次發現以來持續活躍,其 P2P 架構使其難以完全清除。該殭屍網路主要用於 DDoS 攻擊、資料竊取及作為其他惡意活動的跳板。

此 URL 的檔案名稱 `/i` 為 Mozi 常見的惡意載荷命名模式。建議封鎖此 IP 位址並檢查內部網路是否有 IoT 設備嘗試連線至此位址。
