## 威脅描述

此 URL 為 Mirai 殭屍網路針對 ARM4 架構 IoT 設備的惡意 ELF 二進位檔案下載點。ARM4 架構常見於早期嵌入式設備、低階路由器及工業控制設備,這些設備往往缺乏適當的安全更新機制,成為 Mirai 殭屍網路的主要目標。

該 URL 位於 IP 113.30.152.240,與先前觀測到的 ID 3778345(mpsl 變種)共享相同的基礎設施,表明此伺服器託管多種架構的 Mirai 惡意載荷,為典型的多架構分發節點。

## 關聯分析

此 IP 位址(113.30.152.240)同時託管多個 Mirai 變種,包括 mpsl、arm4、arm5、arm7、mips 等不同架構的惡意載荷。此種多架構託管模式為 Mirai 殭屍網路的標準分發策略,感染腳本會嘗試下載並執行所有架構的二進位檔案,直到找到與受害設備相容的版本。

建議將整個 IP 位址列入黑名單,並監控內部網路是否有設備嘗試連線至此 IP 的任何埠或路徑。
