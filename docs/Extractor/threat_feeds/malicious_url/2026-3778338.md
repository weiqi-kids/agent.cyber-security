## 威脅描述

此 URL 為 ClearFake 惡意程式家族的 x64 架構二進位檔案下載點,使用 shadow6nectar.coupons 網域。該網域採用「shadow6nectar」命名模式,與先前觀測到的 ClearFake 基礎設施一致,顯示攻擊者使用系統化的網域生成策略。

子網域 `shad0vv-rnix` 包含數字與字母的混合替換(0 替代 o),為規避自動化偵測的常見手法。

## 關聯分析

`shadow6nectar.coupons` 網域在本次資料集中多次出現(另見 ID 3778327、3778320),證實此為活躍的 ClearFake 惡意程式分發基礎設施。該網域同時託管多個隨機子網域,顯示攻擊者使用通配符 DNS 記錄或快速子網域生成技術。

建議封鎖整個 `*.shadow6nectar.coupons` 網域,並監控使用類似命名模式的 `.coupons` TLD 註冊活動。
