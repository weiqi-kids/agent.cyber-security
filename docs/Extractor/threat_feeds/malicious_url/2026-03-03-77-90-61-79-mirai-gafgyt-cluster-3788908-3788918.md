## 技術分析

### 基礎設施特徵
- **分發伺服器**：77.90.61.79（截至報告時多數仍在線）
- **檔名模式**：`{架構}.dick` — 混淆架構標識（a-r.m-4 = arm4，m-i.p-s = mips 等）

### 多架構 ELF 分析
此伺服器托管針對以下架構的 ELF 二進位：

| 架構 | 目標裝置類型 |
|------|-------------|
| ARM4/5/7 | 舊式嵌入式路由器（Broadcom、Qualcomm 平台） |
| MIPS | 主流家用路由器（TP-Link、D-Link、Netgear） |
| x86-32 | 低功耗 x86 網路裝置 |
| PowerPC | 老式 PowerPC 路由器（某些 Cisco、老式路由器） |
| SuperH | 少見嵌入式系統（日本製裝置） |

### 惡意軟體區分
- **Mirai**：建立 DDoS Botnet，攻擊目標為大型網路基礎設施
- **Gafgyt**（BASHLITE）：與 Mirai 類似但獨立演化，同樣用於 DDoS
