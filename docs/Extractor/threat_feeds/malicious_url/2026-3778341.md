## 威脅描述

此 URL 為 Mirai 殭屍網路針對 ARM7 架構的 ELF 惡意程式下載點。ARM7 處理器廣泛應用於智慧型手機、平板電腦、智慧家電及工業自動化設備,為現代 IoT 生態系統的重要組成部分。

該 URL 託管於已知的 Mirai 分發伺服器 113.30.152.240,與多個同時段報告的相關 URL 共享基礎設施。

## 關聯分析

此 IP 位址為高度活躍的 Mirai 殭屍網路基礎設施,在短時間內被多次報告提供不同架構的惡意載荷。ARM7 架構的載荷特別值得關注,因其應用於大量消費級設備,感染潛力極大。

建議企業網路管理者檢查所有 ARM7 架構設備(特別是智慧監控攝影機、網路印表機及 VoIP 設備)的韌體更新狀態與網路隔離措施。
