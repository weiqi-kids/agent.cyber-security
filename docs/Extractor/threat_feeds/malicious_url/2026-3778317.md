## 威脅描述

此 URL 為 ClearFake 惡意程式的 x64 載荷下載點,使用 breeze1falcon.coupons 網域。此網域命名模式與先前的 shadow6nectar、wildframe41 等網域一致,顯示 ClearFake 攻擊者使用系統化的網域命名策略(「自然詞彙+數字+動物/自然名詞」)。

子網域 br33ze-llnk 使用數字替換字母(3 替代 e),為規避自動化偵測的常見混淆技術。

## 關聯分析

breeze1falcon.coupons 網域在本資料集中多次出現(另見 ID 3778316、3778313),為另一組活躍的 ClearFake 分發基礎設施。該網域與 shadow6nectar.coupons 可能由同一攻擊者控制,作為分散式惡意程式分發網路的一部分。

建議將 breeze1falcon.coupons 與其他已識別的 ClearFake 網域一併封鎖,並監控 .coupons TLD 的新網域註冊活動。
