## 技術分析

- **基礎設施**：兩個獨立 IP（96.44.159.224 和 109.248.151.201）托管結構相似的攻擊資源，可能為同一攻擊者基礎設施
- **載荷類型**：
  - **HTA（HTML Application）**：`ce.hta`、`cw.hta` — 透過 mshta.exe 執行，規避應用白名單

- **目錄結構**：`/21/`、`/113/` 子目錄可能為活動分區或目標分組
- **攻擊手法**：HTA + PHP 組合為常見多階段投放架構，HTA 為初始載入，PHP 動態生成後續載荷
- **威脅評估**：此類基礎設施常見於 APT 行動前期初始存取階段
