## 摘要

RIA to deploy Smart-ID+ functionality in state authentication service by end of February, improving security and preventing fraud and social manipulation.

## 事實內容

The Information System Authority (RIA) of Estonia will implement Smart-ID+ functionality in the state authentication service by the end of February 2026. This upgrade aims to make authentication more secure and user-friendly compared to the current system.

Key benefits of Smart-ID+ include:
- Enhanced security measures
- Improved user experience
- Fraud prevention capabilities
- Protection against social engineering attacks
- Mitigation of various types of scams

This initiative represents a proactive security enhancement to Estonia's national digital identity infrastructure, specifically targeting social manipulation and fraud prevention.

## 受影響系統

- State authentication service
- Smart-ID infrastructure
