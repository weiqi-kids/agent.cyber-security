## 事實內容

On 26th of May we released the IntelMQ Maintenance Version 2.1.3 and on 18th June the Feature Release 2.2.0 . Both versions include various changes, both error corrections and new functionality. We thank all contributors and members of the IntelMQ community for their participation in this community-led project. The Version 2.1.3 mainly fixes errors, for example it improved the error & exception handling and thus the usability. It further contains fixes in 12 bots and even more changes in the core, tests, documentation and supporting tools. Version 2.2.0 introduces several new bots and support for new feeds, including: Github API Collector, Github Feed Parser, CSV Converter Expert, MISP Expert, MISP Feed Output and MISP API Output.
