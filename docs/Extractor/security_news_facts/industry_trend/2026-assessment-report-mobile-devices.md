# NCSC-FI assessment of Lithuanian mobile device security report

**Source**: NCSC-FI (Finland)  
**Link**: https://www.kyberturvallisuuskeskus.fi/en/news/assessment-report-cyber-security-mobile-devices  
**Published**: 2021-10-11

## Summary

NCSC-FI examined the Lithuanian NCSC's report on mobile device security assessment by three manufacturers. NCSC-FI found the content mainly accurate, noting that third-party online shops may affect cyber security.

## Key Points

- **Source**: Lithuania's National Cyber Security Centre report
- **Scope**: Mobile devices from three manufacturers
- **NCSC-FI assessment**: Content mainly accurate
- **Key concern**: Third-party online shops impact on cyber security
- **Context**: International cooperation on mobile security assessment

## Impact

This represents cross-border cooperation among European NCSCs on mobile device security. Third-party app stores pose documented security risks requiring user awareness.
