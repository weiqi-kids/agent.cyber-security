## 概述
加拿大網路安全中心更新 IPv6 安全考量指南 ITSM.80.003,針對 IPv6 部署的資安議題提供建議。

## 主要內容
- **文件編號**: ITSM.80.003
- **文件類型**: Management series(管理系列)
- **涵蓋範圍**:
  - IPv6 安全特性與風險
  - 過渡期間的安全考量
  - 組態強化建議
  - 監控與偵測
  - 最佳實踐

## 影響範圍
- 網路架構師
- 網路管理員
- 資安工程師
- IT管理層

## 備註
隨著 IPv6 逐步普及,其特有的安全考量需要關注。此指南涵蓋 IPv6 部署的完整安全框架。
