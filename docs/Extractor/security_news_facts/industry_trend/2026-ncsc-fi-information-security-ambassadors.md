## Summary

NCSC-FI introduces new information security ambassadors ('turvalistit' or 'securilists') who address common household information security issues to promote smart device safety.

## Details

**Event Type**: Public Awareness Initiative

**Initiative**: Information Security Ambassadors Program

**Key Points**:
- New ambassadors called 'turvalistit' or 'securilists'
- Focus on household information security issues
- Address smart device security at home
- Work with friends and family to solve common issues

**Target Audience**: General public, home users

## Impact Assessment

**Severity**: Low (Awareness Campaign)

**Scope**: National (Finland) - Consumer Focus

**Value**: Increases public awareness of smart device security through peer education model

Source is in English from NCSC-FI. This is a public awareness/education initiative rather than an incident report.
