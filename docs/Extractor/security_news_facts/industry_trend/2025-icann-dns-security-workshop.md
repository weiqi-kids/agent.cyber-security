## 摘要
CERT.LV, NIC.LV, and ICANN are hosting a free one-day intensive workshop on DNS security and DNSSEC technology.

## 事實內容
CERT.LV, in collaboration with NIC.LV (Latvia's national domain registry) and ICANN (Internet Corporation for Assigned Names and Numbers), is organizing a complimentary one-day intensive workshop focusing on DNS security and DNSSEC (Domain Name System Security Extensions). The hands-on workshop aims to enhance understanding of DNS security protocols and implementation practices.

## 受影響系統
- DNS infrastructure
- DNSSEC implementations
