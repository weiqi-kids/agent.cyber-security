## 摘要

Webcheck.PT platform, developed by .PT and CNCS, added new security protocol validations including DANE and Secure TLS Renegotiation to help organizations verify domain compliance with security standards.

## 事實內容

The Webcheck.PT platform has recently added a new set of validations for security protocols and functionalities: DANE and Secure Renegotiation.

New features added:
1. **DANE (DNS-based Authentication of Named Entities)**: Adds an additional layer of protection to web hosting and email services by allowing DNS specification of the certificate to be used for website/email access. Requires DNSSEC implementation as a prerequisite.

2. **Secure Renegotiation**: Verifies whether internet or email servers support secure renegotiation in connection establishment via the TLS protocol.

Webcheck.PT is an online platform developed by .PT (the Portuguese domain registry) and CNCS that allows users to verify in real time the level of compliance of an internet domain and email with the latest standards for secure inter-system communication, such as HTTPS, DNSSEC, and SPF.

## 受影響系統

- Web servers with public-facing domains
- Email servers
- Portuguese organizations seeking DNS/TLS compliance
