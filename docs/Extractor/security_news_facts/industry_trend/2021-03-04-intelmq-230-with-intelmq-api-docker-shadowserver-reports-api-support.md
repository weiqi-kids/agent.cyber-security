## 摘要

IntelMQ 2.3.0 發布，新增 IntelMQ API、Docker 支援、Shadowserver Reports API 整合，並遷移文件至新站點。

## 事實內容

CERT.at 發布 IntelMQ 2.3.0 及其配套工具（IntelMQ Manager、新版 IntelMQ API）。此版本為 2021 年夏季預定的 3.0 版本之重要中間步驟，主要變更包含：(1) 文件遷移至 intelmq.readthedocs.io，整合 Manager 與 API 說明；(2) 使用 Vagrant + Ansible 進行端對端測試；(3) 新增多個 bots：CZ.NIC HAAS/PROKI Parsers（CSIRT.CZ）、ESET Collector/Parser（CERT.EE）、Kafka Collector（CERT.at）、Key-Value Parser、Request Tracker Output（NRDCS.LT）、Shadowserver Reports API 支援；(4) 支援 n6 與 MISP 整合。

## 受影響系統

- IntelMQ 2.3.0
- IntelMQ Manager
- IntelMQ API
