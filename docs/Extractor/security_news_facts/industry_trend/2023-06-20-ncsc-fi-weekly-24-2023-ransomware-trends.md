# The National Cyber Security Centre Finland's weekly review – 24/2023

**Source:** NCSC-FI Security Now!  
**Link:** https://www.kyberturvallisuuskeskus.fi/en/news/national-cyber-security-centre-finlands-weekly-review-242023  
**Published:** 2023-06-20

## Summary

This week's review discusses ransomware development trends and reminds readers not to forget about cyber security during the summer holiday season. Ransomware attacks are being increasingly targeted at backup copies, and in addition to encrypting data, attackers also extort users by threatening to publish their data.

## Key Points

- Ransomware development trends analysis
- Attacks increasingly targeting backup copies
- Double extortion tactics: encryption + data leak threats
- Cyber security reminder for summer holiday season

## Context

Weekly situational awareness report from NCSC-FI covering current cyber security trends and threats in Finland.
