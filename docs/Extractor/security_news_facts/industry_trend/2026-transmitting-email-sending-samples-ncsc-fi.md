## Summary

NCSC-FI provides guidance on how to properly submit suspicious emails and messages for investigation while preserving all necessary technical information and ensuring message authenticity.

## Details

**Event Type**: Technical Guidance Publication

**Key Points**:
- Users can send suspect emails or text messages to NCSC-FI for investigation
- All information that may be extracted from the message must be included
- Specific instructions provided for ensuring authenticity
- Guidance covers conveying information in its original form

**Reporting Scope**:
- Suspected information security breaches
- Suspect emails
- Strange text messages

## Impact Assessment

**Severity**: Low (Guidance/Best Practice)

**Scope**: National (Finland) - All Users

**Educational Value**: Helps Finnish users properly report security incidents with complete technical evidence
