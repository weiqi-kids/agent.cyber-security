## 摘要

Estonia's RIA invites organizations to participate in practical E-ITS (Estonian Information Security Standard) implementation workshops aimed at helping institutions start building an information security management system.

## 事實內容

The Estonian Information System Authority (RIA) invited interested parties to participate in a workshop series on the practical implementation of the Estonian Information Security Standard (E-ITS). The workshops aim to help institutions start building an information security management system and provide the necessary tools to do so. This initiative supports the broader effort to strengthen information security practices across Estonian public sector organizations and increase compliance with the national cybersecurity standard.

## 受影響系統

- Estonian public sector information security management
- E-ITS (Estonian Information Security Standard) compliance
