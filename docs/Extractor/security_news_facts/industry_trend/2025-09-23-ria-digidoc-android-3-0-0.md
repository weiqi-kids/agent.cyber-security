## 摘要

RIA released DigiDoc version 3.0.0 for Android, a generational upgrade built on a modern technology platform while retaining core functionalities; available via Google Play within a week.

## 事實內容

The Estonian Information System Authority (RIA) completed the new version 3.0.0 of RIA DigiDoc for Android devices. This is a generational upgrade — the application is built on a modern technology platform while retaining the existing core functionalities and business logic. The new DigiDoc will reach users through the Google Play Store within a week.

- Application: RIA DigiDoc for Android
- New version: 3.0.0
- Nature: Generational platform upgrade (modern technology stack)
- Distribution: Google Play Store
- Core functions: Retained (digital signing and authentication)

- Android device users in Estonia
