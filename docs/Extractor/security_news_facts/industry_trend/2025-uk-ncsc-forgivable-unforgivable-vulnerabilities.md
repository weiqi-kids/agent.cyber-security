## 摘要

UK NCSC publishes research methodology to assess vulnerability classes and improve implementation of top-level security mitigations.

## 事實內容

The National Cyber Security Centre (UK) has published research designed to help organizations distinguish between "forgivable" and "unforgivable" vulnerability classes. This methodology aims to:

- Provide a framework for evaluating which vulnerability classes should be prioritized for eradication
- Make top-level security mitigations easier to implement across software development lifecycles
- Establish criteria for determining which vulnerabilities represent systemic failures versus acceptable risks

The research offers practical guidance for security teams and developers to focus resources on eliminating the most critical vulnerability categories while managing less severe issues appropriately.
