# Cyber threat level remains elevated, targeted attacks have become more frequent

**Source:** NCSC-FI Security Now!  
**Link:** https://www.kyberturvallisuuskeskus.fi/en/news/cyber-threat-level-remains-elevated-targeted-attacks-have-become-more-frequent  
**Published:** 2023-04-21

## Summary

Attackers are increasingly interested in Finnish organisations. Targeted attacks against carefully selected organisations increasing. Despite increased incident volumes, Traficom and Finnish Security Intelligence Service consider it unlikely that a cyber attack would paralyse Finnish society.
