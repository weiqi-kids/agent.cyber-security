## 摘要

Web data aggregator Bright Data is offering streaming service operators a revenue model that converts smart TV viewers into nodes of a global web proxy network. Apps on Samsung Tizen and LG webOS platforms integrate the Bright SDK, which routes web traffic through users' TV connections. Users opt in exchange for fewer ads, without full understanding of the implications.

## 事實內容

- Web data aggregator Bright Data is pitching streaming service operators on a model that monetizes smart TVs as web proxy nodes.
- Target platforms: Samsung Tizen and LG webOS smart TV operating systems.
- The model works as follows: TV app publishers integrate the Bright SDK into their apps, which allows Bright Data to route third-party web traffic through the viewer's internet connection.
- Viewers "opt in" to the program in exchange for fewer ads — but may not fully understand they are joining a global proxy network.
- This network is used to collect web data for AI training and other purposes, effectively monetizing consumers' bandwidth and IP addresses.
- Privacy implications include: the user's IP address is used for third-party web requests, potentially including scraping, research, and other activities.
- This represents a new vector in the emerging practice of embedding commercial data-collection infrastructure in consumer IoT devices.

## 受影響系統

- Smart TVs running Samsung Tizen
- Smart TVs running LG webOS
- Consumer privacy and home network security
- Streaming service apps integrating the Bright SDK
