## 事實內容

The OWASP Top 10 2025 Web Application Security Risks list has been officially released, showing significant changes in rankings that reflect the rapid evolution of current security threats.

Broken Access Control continues to hold the top position, while Security Misconfiguration and Software Supply Chain vulnerabilities have shown notable ranking changes. The updated list reflects emerging threats and attack patterns observed throughout 2024-2025.

The OWASP Top 10 serves as a critical reference for organizations to prioritize web application security efforts and allocate resources effectively. The 2025 update emphasizes the growing importance of secure configuration management and supply chain security.
