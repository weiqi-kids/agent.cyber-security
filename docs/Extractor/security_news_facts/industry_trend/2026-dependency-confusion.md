# Dependency confusion supply chain attack vector

**Source**: NCSC-FI (Finland)  
**Link**: https://www.kyberturvallisuuskeskus.fi/en/news/dependency-confusion-exposes-attacks  
**Published**: 2021-11-04

## Summary

A researcher successfully hacked systems at Apple, Microsoft and others by exploiting dependency confusion errors in package management. This supply chain attack vector arises when internal and external repositories contain packages with identical names.

## Key Points

- **Attack type**: Supply chain attack via dependency confusion
- **Victims**: Apple, Microsoft, and other major organizations
- **Root cause**: Package management errors in programming languages
- **Condition**: Internal and external repositories with identical package names
- **Impact**: Organizations inadvertently download malicious external packages

## Impact

Dependency confusion demonstrates how subtle package management misconfigurations can compromise even well-resourced organizations. This supply chain risk requires careful repository management practices.
