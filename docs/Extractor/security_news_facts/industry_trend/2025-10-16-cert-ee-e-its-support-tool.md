## 摘要

Estonia's RIA created a web-based E-ITS support application to help organizations systematically assess and develop their information security level in compliance with the Estonian Information Security Standard.

## 事實內容

The Estonian Information System Authority (RIA) created a web-based support application for the Estonian Information Security Standard (E-ITS) that helps organizations systematically assess and develop their information security level. The tool simplifies the implementation of the E-ITS standard by providing structured guidance and assessment capabilities. This represents an important step in increasing adoption of the national information security standard across Estonian organizations, particularly smaller institutions that may lack dedicated security expertise.

## 受影響系統

- E-ITS (Estonian Information Security Standard) compliance
- Estonian organizational information security management
