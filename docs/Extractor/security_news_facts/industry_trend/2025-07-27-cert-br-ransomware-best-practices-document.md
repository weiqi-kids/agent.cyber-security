## 事實內容

CERT.br announced the publication of a new document on ransomware best practices:

Title: "Ransomware: Boas Práticas para Proteção, Detecção e Resposta" (Ransomware: Best Practices for Protection, Detection, and Response)

Document structure (4 parts):
1. Description of how a ransomware attack occurs
2. Best practices for protection
3. Best practices for detection
4. Best practices for response

URL: https://cert.br/docs/ransomware/

This is a foundational cybersecurity resource from Brazil's national CERT covering the full ransomware attack lifecycle and defensive measures.
