## 事實內容

JPCERT/CC published a blog post introducing YAMAGoya, a real-time client monitoring tool designed to address the growing challenge of fileless malware and obfuscation techniques.

Background:
- In recent years, fileless malware and obfuscation techniques have made it increasingly difficult to detect suspicious activity by scanning files alone
- Security researchers and malware analysts actively create and publish detection rules such as Sigma (for log-based detection) and YARA (for memory/file-based detection)

YAMAGoya features:
- **Real-time monitoring**: Provides real-time visibility into client endpoint activity
- **Detection rules**: Leverages both Sigma and YARA rules for comprehensive detection
- **Counter-technique**: Specifically designed to detect threats that evade file scanning

This tool represents JPCERT/CC's contribution to the open-source security community for improving endpoint visibility against modern stealthy attack techniques.
