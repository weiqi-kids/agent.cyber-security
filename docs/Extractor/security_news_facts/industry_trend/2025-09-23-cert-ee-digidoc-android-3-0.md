## 摘要

Estonia's RIA released DigiDoc Android version 3.0.0, a generational upgrade built on a modern technology platform while retaining previous functionality, representing a major rebuild of the digital signing mobile app.

## 事實內容

The Estonian Information System Authority (RIA) completed and released DigiDoc Android version 3.0.0 for Android devices. This is a generational upgrade - the application is built on a modern technology platform while retaining the existing functionality. The new version represents a complete rebuild of Estonia's digital signing mobile application for Android, ensuring long-term maintainability and compatibility with modern Android features. Digital signing via mobile devices is a critical component of Estonia's digital society.

## 受影響系統

- RIA DigiDoc Android application
- Android users of Estonian digital signing services
