## 摘要

UK NCSC technical report on best practices for secure BGP routing protocol implementation.

## 事實內容

The National Cyber Security Centre (UK) has published a technical report on best practice use of the Border Gateway Protocol (BGP), the fundamental data routing protocol that underpins internet connectivity. The report:

- Documents security risks associated with BGP routing
- Provides best practice recommendations for ISP BGP configurations
- Addresses BGP hijacking and route leakage threats
- Recommends implementation of RPKI (Resource Public Key Infrastructure) and route filtering
- Offers guidance on monitoring and detecting BGP anomalies

BGP vulnerabilities have been exploited for traffic interception, denial of service, and espionage. This guidance helps ISPs implement responsible and secure routing practices.

## 受影響系統

- Internet Service Providers (ISPs)
- BGP routing infrastructure
- Autonomous System (AS) operators
- Internet Exchange Points
