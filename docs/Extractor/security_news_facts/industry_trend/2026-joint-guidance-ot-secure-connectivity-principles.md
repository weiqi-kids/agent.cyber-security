## 摘要

Eight international cybersecurity agencies release joint guidance on secure connectivity principles for operational technology environments.

## 事實內容

Canada's Cyber Centre collaborated with seven international partners to release comprehensive guidance on securing operational technology (OT) connectivity.

**Issuing Organizations:**
- Canadian Centre for Cyber Security (Canada)
- National Cyber Security Centre (United Kingdom)
- Australian Cyber Security Centre (Australia)
- Federal Office for Information Security / BSI (Germany)
- National Cyber Security Centre (Netherlands)
- National Cyber Security Centre (New Zealand)
- Cybersecurity and Infrastructure Security Agency / CISA (United States)
- Federal Bureau of Investigation / FBI (United States)

**Purpose:**
The guidance addresses challenges organizations face securing operational technology systems, particularly legacy technologies vulnerable to threat actors. Many OT systems were designed before cybersecurity became a critical consideration, creating inherent vulnerabilities.

**Key Principles Framework:**

The guidance "outlines the desirable end-states that organizations should achieve when designing connectivity into OT environments." These principles serve as "goals rather than minimum requirements," providing flexibility for diverse organizational contexts.

**Goals vs. Requirements:**
The framework recognizes that OT environments vary significantly across industries and organizations. Rather than prescriptive mandates, it provides aspirational principles for:
- Designing new OT connectivity
- Implementing security in greenfield deployments
- Managing and retrofitting existing (brownfield) systems

**Target Audience:**
- System owners responsible for OT infrastructure
- Essential service operators in critical infrastructure sectors
- Organizations implementing industrial control systems
- Security architects designing OT network connectivity

**Implication:**
This multi-national collaboration demonstrates international consensus on OT security challenges and best practices. The principles-based approach allows adaptation to sector-specific requirements while establishing common security objectives across critical infrastructure globally.

## 受影響系統

- Operational Technology (OT) environments
- Industrial Control Systems (ICS)
- Critical infrastructure across multiple sectors
- Legacy OT systems requiring security retrofits
