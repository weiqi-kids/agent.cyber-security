# Information security 2021: Top 3 threats and solutions

**Source**: NCSC-FI (Finland)  
**Link**: https://www.kyberturvallisuuskeskus.fi/en/news/information-security-2021-3-threats-and-3-solutions-everyone  
**Published**: 2021-03-08

## Summary

Top 3 information security threats for 2021: scam traps online and by phone for regular users; for organizations - flimsy remote working solutions, malware and phishing. Article provides practical solutions for both everyday life and workplaces.

## Key Points

- **Individual threats**: Online scam traps, phone scams
- **Organizational threats**: Weak remote work security, malware, phishing
- **Context**: COVID-19 remote work environment
- **Approach**: Practical solutions for different audiences
- **Relevance**: Applicable to everyday life and workplace security

## Impact

Clear articulation of distinct threat profiles for individuals versus organizations helps target security awareness efforts effectively.
