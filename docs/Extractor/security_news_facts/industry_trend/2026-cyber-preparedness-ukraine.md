# Cyber security preparedness guidance for organizations

**Source**: NCSC-FI (Finland)  
**Link**: https://www.kyberturvallisuuskeskus.fi/en/news/cyber-security-preparedness-risks-materialise-instructions-organisations  
**Published**: 2022-03-18

## Summary

The cyber security situation in Finland remains stable with normal communications network performance. Despite rising international tensions, organizations are advised to build solid cyber security foundations as an investment in operational continuity.

## Key Points

- **Current status**: Finland's cyber security situation is stable
- **Communications**: Network performance normal
- **Preparedness**: Telecommunications operators have extensive experience
- **Context**: Organizations concerned about international tensions impact
- **Guidance**: Build solid cyber security foundation for daily operations
- **Approach**: Cyber security as operational continuity investment

## Impact

During geopolitical uncertainty, maintaining focus on fundamental security practices provides resilience. Proactive preparedness is more effective than reactive crisis response.
