## 摘要

Joint guidance providing security best practices to help administrators harden on-premises Microsoft Exchange servers by enforcing a prevention posture and reducing attack surface.

## 事實內容

The Canadian Centre for Cyber Security, in coordination with international partner agencies, released joint guidance on securing on-premises Microsoft Exchange Server installations:

- Provides security best practices for administrators responsible for Exchange Server environments
- Focuses on hardening on-premises Exchange servers through a prevention posture
- Addresses the ongoing targeting of Exchange Server by threat actors (including nation-state actors and ransomware groups)
- Covers configuration hardening, patch management, and monitoring recommendations
- Exchange Server has been the target of significant exploitation campaigns (including historical ProxyLogon, ProxyShell, and other critical vulnerabilities)
- Guidance helps organizations reduce attack surface and detect malicious activity
- Targeted at network defenders and system administrators maintaining Exchange on-premises infrastructure

## 受影響系統

- Microsoft Exchange Server (on-premises)
- Email server infrastructure
- Active Directory environments integrated with Exchange
