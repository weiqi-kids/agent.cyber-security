## 摘要

RIA reminds that from July 2025, Estonia's card manufacturer IDEMIA issues ID cards with a new chip platform; electronic use or client card functionality requires IT system development by service providers.

## 事實內容

The Estonian Information System Authority (RIA) reminds that from the beginning of July, Estonia's card manufacturer IDEMIA issues ID cards with a new chip platform. For the electronic use of these cards or for using the client card functionality, service providers need to make IT system developments. This affects organizations that use Estonian ID cards as client cards or for electronic authentication services.

- Change: New chip platform on Estonian ID cards from IDEMIA (from July 2025)
- Impact: Service providers must develop IT systems to support new cards
- Affected functions: Electronic card use, client card functionality
- Card manufacturer: IDEMIA

## 受影響系統

- Estonian ID card ecosystem (new chip platform)
- Service providers using ID cards as client cards
- IT systems supporting Estonian electronic ID authentication
