# 10 cyber security developments for 2021

**Source**: NCSC-FI (Finland)  
**Link**: https://www.kyberturvallisuuskeskus.fi/en/news/10-cyber-security-developments-look-out-2021  
**Published**: 2021-02-05

## Summary

NCSC-FI forecast sees bleak near future for information security. While the Vastaamo data breach spotlighted security and responsibility questions, 2021 will likely see more incidents. Despite growing emphasis on security and regulatory stability, scams and cyber attacks will continue.

## Key Points

- **Outlook**: Bleak near future for information security
- **Context**: Vastaamo breach raised awareness
- **Positive trends**: Organizations emphasizing security, regulators increasing stability
- **Reality**: Scams and cyber attacks unlikely to be completely avoided
- **Recommendation**: Continued vigilance and investment in security

## Impact

This forecast provides realistic expectations for the threat landscape. Despite improvements, the fundamental challenges of cyber security persist requiring sustained effort.
