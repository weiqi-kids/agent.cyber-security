## 事實內容

We are continuing to support IntelMQ, an open-source solution for collecting and processing security feeds. Recently, the IntelMQ Community announced the release of new version 3.2.0. In the new release, IntelMQ received support for running bots as a library, which should allow for better integration with other tools. A significant contribution from our side is rewriting the IntelMQ API to use a modern FastAPI framework. As usual, this update contains plenty of bug fixes and enhancements. We have improved the performance of some CLI commands, which was previously reported as a significant issue for larger workflows. The complete changelog and release note are available on GitHub .
