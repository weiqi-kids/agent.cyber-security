## 摘要

OWASP officially published the 2025 Top 10 Web Application Security risks. Broken Access Control remains #1; Security Misconfiguration rises to #2; Software Supply Chain Failures newly enters at #3. Two new categories added.

## 事實內容

The 2025 OWASP Top 10 Web Application Security Risk list has been officially published, showing significant changes from previous years.

Key changes:
- **#1 Broken Access Control** — remains at the top position
- **#2 Security Misconfiguration** — significant rise, reflecting growing risks in cloud architecture and third-party component management
- **#3 Software Supply Chain Failures** — significant rise, highlighting increased focus on supply chain security
- **New categories added**: "Software Supply Chain Failures" and "Improper Error Handling"
- **SSRF merged**: Server-Side Request Forgery merged into the Access Control category

This year's list reflects the rapidly evolving threat landscape, particularly around cloud infrastructure, third-party dependencies, and supply chain risks.
