## 事實內容

JPCERT/CC published the TSUBAME Report Overflow covering the monitoring period of April to June 2025. This series focuses on monitoring trends from overseas TSUBAME sensors and activities not included in the main Internet Threat Monitoring Quarterly Reports.

The report discusses fluctuations in threat activities detected by the TSUBAME sensor network during this quarter. TSUBAME (Targeted cyberattacks Uncovering Based on Analyzing darknet and Malware behavior Emulation) is JPCERT/CC's threat monitoring system that observes attack trends globally.

The report provides insights into:
- Monitoring trends from overseas TSUBAME sensors
- Fluctuations in detected threat activities
- Activities and patterns not covered in standard quarterly reports
- Analysis of the April-June 2025 period

This report serves as supplementary intelligence to the main quarterly threat monitoring reports, focusing specifically on overseas sensor data and emerging patterns.
