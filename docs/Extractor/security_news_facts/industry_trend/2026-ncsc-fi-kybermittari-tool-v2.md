# Kybermittari (Cybermeter) v2 helps organizations assess cybersecurity risks

## Summary
NCSC-FI released an updated version of the Kybermittari tool based on user feedback. The new version and support materials are available on the NCSC-FI website, with presentation and training events scheduled for summer and autumn.

## Key Details
- **Tool**: Kybermittari (Cybermeter)
- **Version**: New version based on feedback
- **Purpose**: Cybersecurity risk assessment
- **Availability**: Free on NCSC-FI website
- **Support**: Training events planned

## Context
This represents Finland's effort to provide accessible cybersecurity assessment tools to organizations, enhancing national cyber resilience through self-assessment capabilities.

## Notes
- Practical tool development for risk management
- Community-driven improvement (feedback-based)
