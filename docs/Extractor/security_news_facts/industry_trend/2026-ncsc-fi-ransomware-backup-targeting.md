# Ransomware attacks increasingly target backup copies and use data extortion

## Summary
Ransomware development trends show attackers are increasingly targeting backup copies and combining encryption with data extortion threats (threatening to publish stolen data).

## Key Details
- **Trend**: Targeting of backup copies
- **Evolution**: Dual extortion (encryption + publication threats)
- **Context**: Summer 2023 analysis
- **Reminder**: Cyber security during holiday season

## Context
This represents an evolution in ransomware tactics, making recovery more difficult by targeting backups while adding leverage through data publication threats.

## Notes
- Important trend analysis for ransomware evolution
- Highlights need for offline/immutable backups
- Confidence: high
