## 摘要

JPCERT/CC introduces YAMAGoya, a real-time client monitoring tool that uses Sigma and YARA rules to detect fileless malware and obfuscated threats that traditional file scanning cannot identify.

## 事實內容

In response to the increasing difficulty of detecting fileless malware and obfuscated threats through file scanning alone, security researchers have developed YAMAGoya, a real-time client monitoring tool. The tool leverages publicly available detection rules (Sigma and YARA) created by the security community to identify suspicious activity on endpoints. This represents an evolution in endpoint detection capabilities, addressing modern evasion techniques used by threat actors.

## 受影響系統

- Endpoint monitoring systems
- Security operations centers (SOC)
