## 摘要

Microsoft transitioning to Entra ID authentication, BadBox 2.0 malware threat highlighted.

## 事實內容

This week's review covers important updates:
- Microsoft will begin transitioning to Entra ID authentication methods in autumn 2025
- Organizations advised to start preparing well in advance
- Threat posed by BadBox 2.0 malware highlighted
- BadBox can be embedded in devices during manufacturing (supply chain threat)

The Entra ID transition represents a significant change for Microsoft 365 environments.

## 受影響系統

- Microsoft 365 environments (Entra ID transition)
- Devices with pre-installed BadBox 2.0 malware
