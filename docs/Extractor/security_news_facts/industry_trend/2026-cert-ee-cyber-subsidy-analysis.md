## Summary
Recent analysis shows Estonia's cyber subsidy program reached companies that otherwise wouldn't have purchased cybersecurity services, increased provider competition, and lowered prices.

## Facts Content
**Program**: Küberpööre (Cyber Turnaround) subsidy
**Analysis Subject**: Program effectiveness evaluation

**Key Findings**:
- Subsidy reached companies that wouldn't otherwise buy cybersecurity services
- Increased number of cybersecurity service providers
- Competition reduced price levels
- Enabled more companies to improve security cost-effectively

**Impact**:
