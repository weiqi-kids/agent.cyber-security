## Summary
Estonia launches public testing of mobile e-voting application prototype from May 20-22, 2025, with iOS and Android apps available via valimised.ee.

## Facts Content
**Test Period**: May 20, 2025 (09:00) - May 22, 2025 (20:00)
**Service**: Mobile phone e-voting application prototype

**Supported Platforms**:
- iOS operating system
- Android operating system
- Access via: valimised.ee website

**Organizers**:
- Information System Authority (RIA)
- State Electoral Office

**Test Theme**: "Time travel through Estonian history" - participants vote for historical events they would like to experience

**Purpose**: Public testing of voter application functionality and user experience

**Notes**:
- Original language: Estonian
- Creative engagement through historical voting theme
- Three-day public testing window
- Represents evolution from computer-based to mobile voting
