## 摘要

JPCERT introduces YAMAGoya, a new real-time client monitoring tool that uses Sigma and YARA detection rules to counter fileless malware and obfuscation techniques.

## 事實內容

In recent years, fileless malware and obfuscation techniques have made it increasingly difficult to detect suspicious activity by scanning files alone. To counter these threats, security researchers and malware analysts actively create and publish detection rules such as Sigma and YARA. JPCERT/CC has introduced YAMAGoya, a real-time client monitoring tool that leverages these detection rules to enhance threat detection capabilities.

The tool addresses the growing challenge where traditional file-based scanning is insufficient against modern attack techniques, providing security teams with enhanced visibility into client-side activities through established detection rule frameworks.

## 受影響系統

- Client endpoints requiring real-time monitoring
- Security operations centers (SOC)
