## 摘要

Check Point Research highlights how blockchain whitelists, intended as security measures, have become critical attack vectors for nation-state groups. When significant assets are held on a public blockchain, whitelists reveal exactly which vendors and counterparties to compromise. Notable incidents include Bybit ($1.5B), WazirX ($235M), and Radiant ($53M), all of which had whitelists and were drained through whitelisted entities. The research argues that static access control must be replaced with continuous, real-time transaction validation and monitoring, as every whitelisted address should be treated as potentially compromised.

Check Point 研究揭示區塊鏈白名單（原本作為安全措施）如何成為國家級駭客團體的關鍵攻擊向量。當公共區塊鏈上持有大量資產時，白名單正好告訴攻擊者應入侵哪些供應商和交易對手。重大事件包括 Bybit（15 億美元）、WazirX（2.35 億美元）和 Radiant（5,300 萬美元），它們都有白名單，且全部透過白名單實體被掏空。研究主張靜態存取控制必須被持續性即時交易驗證和監控所取代，因為每個白名單地址都應被視為可能已遭入侵。
