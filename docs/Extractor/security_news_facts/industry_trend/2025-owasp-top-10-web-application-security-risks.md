## Factual Content

The 2025 OWASP Top 10 Web Application Security Risk list was officially released, showing significant ranking changes this year reflecting rapid evolution of current security threats. Broken Access Control continues to top the list, while Security Misconfiguration and Software Supply Chain Failures have jumped to second and third positions, indicating enterprises face greater challenges in cloud architecture and third-party component management.

The 2025 OWASP Top 10 Web Application Security Risk list added two new categories: "Software Supply Chain Failures" and "Mishandling of Exceptional Conditions," while merging Server-Side Request Forgery (SSRF) into "Broken Access Control." Among these, "Software Supply Chain Failures" entered the top three for the first time, highlighting increasing risks from open-source packages and third-party services. While "Cryptographic Failures" and "Injection" remain on the list, their rankings have dropped, showing organizations have accumulated certain protective capabilities against these vulnerabilities. Finally, the new category "Mishandling of Exceptional Conditions" covers software performance under unpredictable stress, from poor error handling to logic collapse. As system interconnection and AI-driven trends continue, risks in this area are gradually rising.

The complete 2025 OWASP Top 10 ranking:

1. **A01:2025 - Broken Access Control**: Allows attackers to bypass authorization or gain unauthorized access
2. **A02:2025 - Security Misconfiguration**: Incorrect configuration of systems, applications, or cloud services
3. **A03:2025 - Software Supply Chain Failures**: Interruptions or issues during third-party software build, distribution, or update processes
4. **A04:2025 - Cryptographic Failures**: Lack of encryption, insufficient encryption strength, encryption key leaks, and related errors
5. **A05:2025 - Injection**: Attackers insert malicious code or commands into input fields
6. **A06:2025 - Insecure Design**: Design and architectural flaws covering application logic errors
7. **A07:2025 - Authentication Failures**: Attackers trick systems into identifying invalid or incorrect users as legitimate users
8. **A08:2025 - Software or Data Integrity Failures**: Failure to effectively prevent treating invalid or untrusted code or data as trustworthy valid data
9. **A09:2025 - Logging & Alerting Failures**: Lack of logging and alerting making it impossible to detect attacks and vulnerabilities, hindering quick effective response
10. **A10:2025 - Mishandling of Exceptional Conditions**: Includes open failures, improper error handling, logic errors, and other exceptional conditions systems may encounter

## Affected Systems

- All web applications and systems
- Cloud-based services and infrastructure
- Third-party components and supply chain systems
