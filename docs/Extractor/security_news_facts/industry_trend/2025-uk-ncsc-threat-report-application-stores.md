## 摘要

UK NCSC report outlining security risks associated with official and third-party application stores.

## 事實內容

The National Cyber Security Centre (UK) has published a comprehensive threat report examining the risks associated with the use of both official and third-party application stores. The report:

- Identifies security risks specific to official app stores (Apple App Store, Google Play, etc.)
- Analyzes heightened threats from third-party and unofficial app stores
- Documents malware distribution methods through app marketplaces
- Provides risk assessment framework for organizations evaluating app sources
- Recommends security controls for managing app installation risks

The analysis helps organizations and individuals make informed decisions about application download sources and implement appropriate security measures.

## 受影響系統

- Mobile device users (iOS, Android)
- Enterprise mobile device management systems
- Application developers and publishers
