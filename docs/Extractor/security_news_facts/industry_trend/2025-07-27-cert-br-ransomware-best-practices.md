## Factual Content

CERT.br has published a new comprehensive document on ransomware best practices titled "Ransomware: Boas Praticas para Protecao, Deteccao e Resposta" (Ransomware: Best Practices for Protection, Detection, and Response). The document is divided into 4 parts:

1. Description of how a ransomware attack occurs
2. Best practices for protection
3. Best practices for detection
4. Best practices for response
