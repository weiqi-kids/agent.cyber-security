## Summary
Estonia's Information System Authority completes technical prototype for mobile voting (m-voting) application as technical and innovation partner to State Electoral Service.

## Facts Content
**Milestone**: M-voting technical prototype completed
**Developer**: Information System Authority (RIA)
**Partner**: State Electoral Service (Riigi valimisteenistus)

**RIA Responsibilities**:
- Election information system development
- E-voting system operation
- M-voting application development

**Priority Objective**: Develop suitable and secure mobile voting application

**Significance**:
- Major milestone in mobile voting development
- Extends Estonia's e-voting leadership to mobile platforms
- Technical foundation for future mobile voting implementation

**Notes**:
- Original language: Estonian
- Evolution from computer-based to mobile voting
- Estonia pioneered internet voting in 2005
- Prototype stage, not yet deployed for actual elections
