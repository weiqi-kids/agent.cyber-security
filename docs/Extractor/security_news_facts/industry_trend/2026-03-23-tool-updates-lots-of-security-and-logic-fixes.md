## 摘要

SANS ISC handler shares experience using Claude AI to conduct security reviews of Python scripts, finding multiple previously undetected bugs and logic errors, illustrating AI-assisted code security review as an emerging practice.

## 事實內容

A SANS ISC handler published a diary entry about their experience using Claude Code/OpenCode/Codex for security review of Python scripts. The handler asked Claude to perform a `/security-review` on several scripts and found more issues than expected.

**Key findings:**
- AI code review identified genuine security bugs and logic errors that had existed undetected for an extended period
- The review process itself was fast for the AI; the human review of AI suggestions took longer
- The handler accepted most suggestions after reviewing them, making tweaks as needed
- No "earth-shattering" findings, but meaningful improvements to script security and correctness

**Industry trend significance:** This diary entry illustrates the growing adoption of AI-assisted security code review tools (Claude Code, OpenCode, Codex, OpenClaw) as part of standard developer security workflows.
