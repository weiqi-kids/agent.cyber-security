## 摘要

Canadian Centre for Cyber Security announces the release of the Ransomware Threat Outlook 2025-2027, a forward-looking threat assessment on ransomware trends affecting Canadian organizations.

## 事實內容

The Canadian Centre for Cyber Security (Cyber Centre) released the Ransomware Threat Outlook 2025-2027. This publication is an update to the Cyber Centre's Baseline cyber threat assessment and provides a forward-looking analysis of the ransomware threat landscape. The report covers the ransomware threat ecosystem, the state of ransomware in Canada, key judgments on future trends, myths and misconceptions, and an outlook for 2025-2027. The news release was issued by the Communications Security Establishment Canada. The full report is available at the Cyber Centre website.

## 受影響系統

- Critical infrastructure operators
