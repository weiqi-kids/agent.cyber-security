# Kybermittari (Cybermeter) helps to perceive cybersecurity risks

**Source:** NCSC-FI Security Now!  
**Link:** https://www.kyberturvallisuuskeskus.fi/en/news/kybermittari-cybermeter-helps-perceive-cybersecurity-risks  
**Published:** 2023-06-02

## Summary

A new version of the Kybermittari tool has been developed based on user feedback. The new version of Kybermittari as well as new support material are available on the NCSC-FI website. Registration for Kybermittari presentation and training events to be held in summer and autumn.

## Key Points

- Updated Kybermittari tool released
- Based on user feedback
- New support material available
- Training events scheduled for summer/autumn

## Context

NCSC-FI tool update to help organizations assess and improve their cybersecurity posture.
