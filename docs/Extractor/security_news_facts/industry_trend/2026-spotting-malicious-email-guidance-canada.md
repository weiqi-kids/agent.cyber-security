## 摘要

Canadian Cyber Centre publishes updated awareness guidance on identifying and handling malicious emails, including new quishing (QR code phishing) threats.

## 事實內容

The Canadian Centre for Cyber Security has published ITSAP.00.100 (Awareness series, January 2026), providing comprehensive guidance for employees on spotting and handling malicious email messages.

**Threat Actor Tactics:**
- Steal sign-in credentials
- Spread malware (viruses, ransomware, spyware)
- Steal information, corrupt or damage files
- Target organizations and networks to access sensitive information

**Phishing Attack Types:**
- **Spear-phishing**: Emails to specific targets using personal/professional characteristics
- **Whaling**: Emails to high-profile individuals or senior executives
- **Quishing**: NEW threat using malicious QR codes in emails that redirect to malicious websites

**High-Risk Targets:**
- Senior executives and assistants
- Helpdesk staff
- System administrators
- Users with access to sensitive information
- Users with remote access
- Users interacting with the public

**Recognition Indicators:**
- Unfamiliar or misspelled sender names/addresses
- Invalid username or domain name
- Altered or unprofessional company logos
- Generic or odd greetings
- Poor grammar or spelling
- Urgent tone and direction to act quickly
- Urgent messages about current "hot-button" issues
- Unusual requests (e.g., requests for sensitive information via email)

**Note on AI-Generated Phishing:** Document warns that malicious emails created using generative AI tools may not contain traditional telltale poor grammar or spelling.

**Protection Best Practices:**
- Do not click links, attachments, or QR codes in unsolicited emails
- Report suspicious emails to IT/security teams
- Use email filters to block malicious content
- Delete junk folder items regularly
- Set up client portals for document collection
- Use secure messaging portals instead of email for personal information
- Configure office suite to prevent macros from running without confirmation
- Deactivate automatic downloads of attachments and images
- Configure inbox to not load external images (mitigate tracking pixels)

**Organizational Policy Recommendations:**
- Install and configure firewall and anti-malware software
- Configure protective DNS on devices, modems, routers
- Enable software allowed list and regular updates
- Implement quarantine functions in anti-malware software
- Use trusted AI detector tools to verify content authenticity
- Omit sensitive information when using AI tools

**Incident Response (if malicious email accessed):**
1. Stop using device
2. Disable Wi-Fi or disconnect network cables
3. Power off device
4. Contact IT security department
5. Change passwords on different device
6. Scan device with anti-malware software
7. Restore network connections only when system is clean
8. Perform updates and security patches
9. Monitor accounts for suspicious activity

The document emphasizes that "no one is immune" to phishing attacks and stresses proactive verification of email legitimacy.

## 受影響系統

- Email platforms and systems
- Corporate networks
- Employee devices (workstations, mobile devices)
- Office suite applications (document macros)
