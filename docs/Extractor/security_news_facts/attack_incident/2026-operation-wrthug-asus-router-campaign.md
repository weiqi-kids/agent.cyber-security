## 摘要

Global cyber threat campaign "Operation WrtHug" targets ASUS routers. Users urged to immediately update firmware to prevent compromise.

## 事實內容

A global network threat campaign named "Operation WrtHug" has been identified targeting ASUS routers. The campaign exploits vulnerabilities in ASUS router firmware to compromise devices and potentially use them as part of botnet infrastructure or for lateral movement within networks. ASUS users are strongly advised to immediately update router firmware to latest versions to mitigate exploitation risk.

**Attack Characteristics**:
- Targets ASUS router models with known vulnerabilities
- Potential for device compromise and network infiltration
- May leverage routers for command and control infrastructure
- Global scope of threat campaign

**Mitigation**:
- Immediately update ASUS router firmware to latest patched versions
- Review router security settings and access controls
- Monitor for suspicious network activity or unauthorized access

## 受影響系統

- ASUS router models with unpatched firmware vulnerabilities
