## 摘要
Instagram fixed a bug allowing mass password reset emails, amid claims that data from over 17 million Instagram accounts were stolen and leaked on forums.

## 事實內容
Instagram claims to have fixed a bug that allowed an external party to request password reset emails for some Instagram users on a massive scale. "We fixed an issue that allowed an external party to request password reset emails for some Instagram users," a Meta spokesperson told BleepingComputer. This incident coincides with claims that data from more than 17 million Instagram accounts were stolen and leaked on forums, though Meta denies this represents a new breach. The mass password reset requests could indicate either a technical vulnerability or an attempted credential stuffing attack leveraging previously leaked data.

## 受影響系統
- Instagram user accounts
- Potentially 17 million accounts with leaked data
