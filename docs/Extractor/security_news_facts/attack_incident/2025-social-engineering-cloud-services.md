# 社交工程手法再升級：結合雲端服務與短期憑證規避防禦

## 摘要
TWCERT/CC 接獲外部情資，近期出現一波結合雲端服務與仿冒網域的社交工程攻擊活動。攻擊者透過租用 Microsoft 365 服務、註冊近似官方的域名，並申請短期 SSL 憑證，試圖規避郵件與網頁防禦機制，發起釣魚郵件攻擊。

## 事實陳述

### 攻擊手法
- **雲端服務濫用**: 攻擊者租用合法的 Microsoft 365 服務作為攻擊基礎設施
- **網域仿冒**: 註冊與目標組織官方域名高度相似的仿冒域名
- **SSL 憑證申請**: 為仿冒網域申請短期 SSL 憑證，增加釣魚網站可信度
- **防禦規避**: 利用合法雲端服務和有效 SSL 憑證繞過傳統郵件與網頁安全防護機制
- **攻擊向量**: 發送釣魚郵件作為主要攻擊途徑

### 影響範圍
- **情資來源**: 外部情資通報至 TWCERT/CC
- **攻擊性質**: 針對性社交工程攻擊活動
- **時間範圍**: 近期發現的持續性威脅活動

### 技術細節
- **基礎設施**: Microsoft 365 雲端服務
- **憑證類型**: 短期 SSL/TLS 憑證
- **攻擊鏈**: 仿冒域名 → SSL 憑證申請 → 釣魚郵件發送 → 誘導受害者訪問仿冒網站
