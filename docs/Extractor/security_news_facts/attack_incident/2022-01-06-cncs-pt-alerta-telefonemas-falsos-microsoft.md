## 摘要

Portugal's CERT.PT issued an alert about an increase in fraudulent phone calls impersonating Microsoft employees, tricking victims into installing malware or remote access software to steal credentials and credit card data.

## 事實內容

CNCS/CERT.PT observed an increasing number of fraudulent phone calls made in the name of Microsoft that attempt to:
1. Convince victims to install malicious programs on their computers, with the intent of stealing information and/or encrypting machine contents (ransomware behavior)
2. Access victims' credit card details by inducing them to install remote access software, enabling attackers to access sensitive data

**Attack method**: Social engineering via phone (vishing); victims are impersonated by fake Microsoft employees. Once remote access software is installed, attackers can exfiltrate sensitive data or deploy ransomware.

**CNCS recommendations**:
- Do not respond to such calls
- Do not provide any personal data
- Report incidents to CERT.PT
- If damage occurred, file a criminal complaint with the Judiciary Police or via the Electronic Complaint Portal

## 受影響系統

- Windows PC users (general public)
- Organizations with employees susceptible to vishing attacks
