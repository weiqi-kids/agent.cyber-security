# Phishing attacks impersonating banks via email malware

## Summary
Weekly review covers phishing attacks where scammers impersonate banks and spread malware via email. Also includes guidance on children's first smart devices.

## Key Details
- **Attack Type**: Phishing impersonating banks
- **Vector**: Email-based malware
- **Additional Topic**: Child device security awareness
- **Timeline**: Early June 2023

## Context
Bank impersonation remains a persistent threat vector, with email serving as primary delivery mechanism for both phishing and malware.
