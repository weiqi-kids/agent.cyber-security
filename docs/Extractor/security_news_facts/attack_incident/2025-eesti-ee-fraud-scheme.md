# Fraudsters Used eesti.ee Data in Scam Schemes

## Summary
Approximately 1,500 people fell victim to social engineering, granting fraudsters access to their eesti.ee accounts, which was not a data leak or security weakness but manipulation.

## Factual Content
According to the Police and Border Guard Board and the Information System Authority (RIA), approximately 1,500 people gave access to their eesti.ee account as a result of fraudster manipulation. This was not a data leak or security weakness. The fraudsters' goal was to use data found there to build trust and extort money.

**Key Points:**
- Victims: Approximately 1,500 people
- Attack type: Social engineering/manipulation
- Target: eesti.ee accounts
- Not a breach: No data leak or security vulnerability
- Fraudster goal: Build trust using stolen data, extort money
- Clarification: Manipulation-based, not technical vulnerability
