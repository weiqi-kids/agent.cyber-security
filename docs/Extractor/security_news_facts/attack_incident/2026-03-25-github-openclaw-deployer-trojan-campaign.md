## 摘要

AI-assisted campaign "TroyDen's Lure Factory" spread 300+ Trojanized GitHub packages targeting developers and gamers with a data-stealing Trojan, hiding behind OpenClaw Docker deployer and other popular lures.

## 事實內容

Netskope Threat Labs identified a widespread campaign called "TroyDen's Lure Factory" spreading Trojanized packages on GitHub:

Attack details:
- Over 300 Trojanized GitHub packages identified
- Targets: Developers and gamers
- Payload: Data-stealing Trojan
- Campaign uses AI assistance for distribution

Lures used:
- OpenClaw Docker deployer (viral AI development tool)
- Another AI developer tool
- Telegram-promoted phone tracker
- Fishing Planet game cheat
- Roblox scripts
- Crypto bots
- VPN crackers

Attack method: Supply chain attack via malicious open-source packages on GitHub

Detection source: Netskope Threat Labs

## 受影響系統

- Developers downloading packages from GitHub
- Gamers downloading game cheats/tools
- Developer workstations and CI/CD environments
