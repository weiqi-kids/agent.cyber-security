## 摘要

Slovakia's NCSC warns of compromised NPM packages with malicious code, totaling 2.6 billion weekly downloads, threatening vast number of dependent products.

## 事實內容

Slovakia's National Cybersecurity Centre warns of compromised NPM packages containing malicious code. Multiple packages with a total of up to 2.6 billion weekly downloads are affected. This threatens an enormous number of additional products that use these packages. Security researchers at Aikido identified the compromise of eighteen software packages with over 2 billion weekly downloads collectively. These packages are widely used in the JavaScript/Node.js ecosystem.

## 攻擊手法

- Supply chain attack on NPM packages
- Malicious code injection into popular libraries
- Wide-scale dependency compromise

## 受影響系統

- NPM package ecosystem
- JavaScript/Node.js applications using affected packages
- Downstream products and services
