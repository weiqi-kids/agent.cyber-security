## 摘要

CISA issued a warning about spyware attacks targeting messaging app users, including account hijacking via phishing/QR codes, zero-click exploits, and fake app distribution. CISA also updated mobile communications best practices guidance.

## 事實內容

The US Cybersecurity and Infrastructure Security Agency (CISA) issued an advisory titled "Spyware Allows Cyber Threat Actors to Target Users of Messaging Applications" and updated its Mobile Communications Best Practice Guidance.

Key attack methods observed:
1. **Account hijacking**: Using phishing and malicious QR codes to link accounts to attacker-controlled devices
2. **Zero-click exploits**: Malware implanted without any user interaction required
3. **Fake applications**: Counterfeit versions of Signal, WhatsApp, and other messaging apps containing malicious code

CISA's key security recommendations include:
- Implement end-to-end encryption (E2EE) for all communications
- Review application privacy policies carefully
- Prioritize platforms with E2EE enabled by default
- Remain alert to system prompts requesting "re-authentication" or "new device linking" — common account hijacking methods

## 受影響系統

- Commercial messaging applications (Signal, WhatsApp, and similar platforms)
- Mobile devices running iOS and Android
