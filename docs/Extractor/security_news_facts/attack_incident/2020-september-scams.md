## 摘要

Scam messages impersonating Posti and Zerologon vulnerability marked September 2020 cyber weather.

## 事實內容

September 2020 saw widespread scam text messages sent in Posti's (Finnish postal service) name targeting thousands of Finns. The month also featured concerns about the critical Zerologon vulnerability and Emotet malware strain. These combined threats created challenging cybersecurity conditions across Finland.

## 受影響系統

- Finnish mobile users
- Active Directory domain controllers (Zerologon)
- Systems vulnerable to Emotet
