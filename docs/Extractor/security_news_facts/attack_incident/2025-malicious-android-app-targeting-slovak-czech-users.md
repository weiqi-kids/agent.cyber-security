## 摘要

ThreatFabric researchers discovered malicious Android apps targeting Czech and Slovak markets for sophisticated money and cryptocurrency theft.

## 事實內容

Security researchers at ThreatFabric discovered new malicious applications for Android operating system directly targeting the Czech and Slovak markets. These applications enable sophisticated theft of money and cryptocurrencies from users' mobile phones. The malicious code is distributed as a series of applications, with users lured into installing the first one through deceptive advertising. The campaign represents a targeted attack on Central European banking customers.

## 攻擊手法

- Malicious Android applications
- Deceptive advertising for app distribution
- Banking credential and cryptocurrency theft

## 受影響系統

- Android mobile devices
- Czech and Slovak banking customers
