## 摘要
CNCS issued an alert about an increase in fraudulent phone calls impersonating Microsoft employees, tricking victims into installing malicious software or remote access tools to steal information, encrypt files, or gain access to credit card details.

## 事實內容
CNCS observed a notable increase in fraudulent phone calls in Portugal where scammers impersonate Microsoft employees:

**Attack method**:
- Callers claim to be Microsoft support staff
- Convince victims to install malicious software on their computers
- Alternatively, trick victims into installing remote access software
- Goal: Steal personal/financial information and/or encrypt machine contents (ransomware)
- Also attempt to obtain victims' credit card details

**Victim instructions**:
- Do NOT respond to these calls
- Do NOT provide any personal data
- Report to CERT.PT if victimized: https://www.cncs.gov.pt/pt/notificacao-incidentes/
- If financial damage occurred: file a criminal complaint with the Judicial Police (Polícia Judiciária) or via the Online Complaint Portal (https://qe.pj.pt/login)

**Threat classification**: Social engineering / vishing attack targeting Portuguese citizens

## 受影響系統
- Individual computer users in Portugal
- Home computers and devices with remote access
