## 摘要

A threat actor claims to be selling 590 TB of data allegedly exfiltrated from OVHcloud, including 1.6 million customer records and data from 5.9 million websites, though OVHcloud CEO stated the sample dataset was not found in their database.

## 事實內容

A high-profile threat actor is allegedly selling a massive data haul from OVHcloud (one of Europe's largest cloud/hosting providers):

Claimed data:
- 590 Terabytes (TB) total
- 1.6 million "fresh" customer records
- Active data from 5.9 million websites
- Full website source code
- SQL and NoSQL databases
- Sensitive server configurations

Alleged compromise method: Compromise of a "parent account" with overarching administrative privileges

Verification status:
- UNCONFIRMED
- "Proof of Work" samples have been released on dark web forums
- OVHcloud Founder and CEO Octave Klaba posted on X that the sample dataset was NOT found in their database

Recommended immediate actions (from the report):
- Immediate credential rotation
- API key invalidation
- Implementation of FIDO2/WebAuthn MFA

Note: Confidence is set to "中" (medium) because the breach is unconfirmed and OVHcloud has disputed the samples.

## 受影響系統

- OVHcloud infrastructure
- Customers of OVHcloud (1.6 million potentially affected)
- Websites hosted on OVHcloud (5.9 million potentially affected)
