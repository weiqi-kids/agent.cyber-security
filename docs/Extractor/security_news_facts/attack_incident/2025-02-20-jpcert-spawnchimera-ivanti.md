## 摘要

SPAWNCHIMERA malware campaign targeting Ivanti Connect Secure vulnerabilities.

## 事實內容

In January 2025, Ivanti published an advisory regarding vulnerabilities in Ivanti Connect Secure. JPCERT/CC has identified a malware campaign dubbed "SPAWNCHIMERA" that exploits these vulnerabilities to compromise target systems.

The malware name "SPAWNCHIMERA" suggests a sophisticated threat that spawns or originates from Ivanti Connect Secure vulnerability exploitation. This represents a targeted attack campaign against organizations using Ivanti's VPN and secure access solutions.

Ivanti Connect Secure is widely deployed in enterprise environments for remote access, making this a high-value target for threat actors seeking initial access to corporate networks. The exploitation of these vulnerabilities allows attackers to bypass security controls and establish persistent access to compromised networks.

## 受影響系統

- Ivanti Connect Secure (multiple versions)
