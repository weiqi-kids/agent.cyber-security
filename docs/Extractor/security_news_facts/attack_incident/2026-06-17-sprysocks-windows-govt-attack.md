## 摘要

中國威脅組織 Earth Lusca 使用 SprySOCKS 惡意軟體的 Windows 變體，攻擊台灣、泰國、巴基斯坦和洪都拉斯的政府組織。

## 事實內容

ESET 研究人員發現 SprySOCKS Linux 惡意軟體的 Windows 變體，被用於 2023 至 2024 年間針對至少四個國家政府組織的攻擊。

SprySOCKS 與中國威脅組織「Earth Lusca」有關聯，該組織先前以 Linux 版本攻擊外交事務、科技和電信領域的政府實體。現發現的 Windows 變體針對台灣、泰國、巴基斯坦和洪都拉斯的政府組織發動攻擊。

- 威脅行為者：Earth Lusca（中國）
- 惡意軟體：SprySOCKS（Windows 變體）
- 攻擊目標：政府組織（外交、科技、電信）
- 受攻擊國家：台灣、泰國、巴基斯坦、洪都拉斯
- 攻擊時間：2023 至 2024 年間

## 受影響系統

- Windows 作業系統（政府組織）
- 外交事務、科技、電信部門網路
