## 摘要

JPCERT/CC reports DslogdRAT malware targeting Ivanti Connect Secure, observed in attacks beyond the previously reported SPAWNCHIMERA malware.

## 事實內容

**Context**:
- Previous JPCERT/CC Eyes article reported SPAWNCHIMERA malware infecting Ivanti Connect Secure
- DslogdRAT represents a different malware strain used in recent attacks

**Malware Details**:
- **Name**: DslogdRAT
- **Target**: Ivanti Connect Secure
- **Attack Method**: Exploiting vulnerabilities in Ivanti Connect Secure
- **Relationship**: This is NOT the only malware observed; multiple malware families targeting same product

**Significance**:
Multiple threat actors are deploying different malware families against Ivanti Connect Secure, indicating:
- High value target
- Multiple independent attack campaigns
- Diverse threat actor interest

## 受影響系統

- Ivanti Connect Secure (VPN appliance)
- Organizations using vulnerable Ivanti Connect Secure instances
