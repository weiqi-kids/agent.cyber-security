# 2020 cyber security review: Vastaamo, pandemic, and remote work

**Source**: NCSC-FI (Finland)  
**Link**: https://www.kyberturvallisuuskeskus.fi/en/news/2020-was-tumultuous-year-during-which-cyber-security-was-everyones-lips  
**Published**: 2021-03-04

## Summary

2020 was tumultuous for information security. Key events included the Vastaamo data breach, pandemic-driven remote work, the Koronavilkku app, Emotet malware, and technical support scams. 5G security regulation also garnered significant discussion.

## Key Points

- **Vastaamo breach**: Major psychotherapy patient data breach
- **Pandemic impact**: Remote work security challenges
- **Koronavilkku**: Finnish COVID-19 contact tracing app
- **Emotet**: Continued malware threat
- **Tech support scams**: Persistent fraud
- **5G security**: Regulatory discussion
- **Overall**: Tumultuous year putting cyber security in spotlight

## Impact

2020 marked a watershed year for cyber security awareness in Finland. The combination of high-profile breaches and pandemic disruption elevated security from technical concern to public issue.
