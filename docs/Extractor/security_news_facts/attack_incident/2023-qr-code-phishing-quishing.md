## 摘要

Quishing (QR code phishing) emerging as new attack method, exploiting smartphone QR code recognition features.

## 事實內容

New phishing technique:
- 'Quishing' is phishing carried out using QR code
- Victims lured to scan QR code with smartphone or tablet
- QR codes easy to open using built-in camera recognition
- New attack vector exploiting mobile device convenience

Emerging threat leveraging QR code ubiquity.

## 受影響系統

- Smartphone users
- Tablet users
