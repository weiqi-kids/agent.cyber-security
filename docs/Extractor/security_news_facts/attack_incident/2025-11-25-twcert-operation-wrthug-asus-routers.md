## 摘要

SecurityScorecard STRIKE team reveals "Operation WrtHug" — a large-scale campaign exploiting known vulnerabilities in ASUS routers to recruit infected devices into a global threat operation network.

## 事實內容

TWCERT/CC issued an emergency alert regarding "Operation WrtHug," a large-scale global cyber operation targeting ASUS routers, as disclosed by SecurityScorecard's STRIKE team.

Key findings:
- **Campaign name**: Operation WrtHug
- **Targets**: ASUS routers globally, including consumer and enterprise models
- **Attack method**: Exploitation of known vulnerabilities in ASUS router firmware to gain unauthorized access
- **Purpose**: Infected devices are recruited into a botnet-like network used as infrastructure for further cyber threat operations — potentially including proxying malicious traffic, launching distributed attacks, or enabling lateral movement into connected networks
- **Scale**: Large-scale, affecting routers across multiple countries
- **Threat actor**: Attribution not conclusively established at time of publication

Key risks:
- Compromised routers can intercept network traffic, enabling credential theft and man-in-the-middle attacks
- Infected routers can be used to launch attacks against other organizations while masking the true attacker origin
- Home and small office users with default or unpatched firmware are particularly vulnerable

TWCERT/CC strongly recommends ASUS router users to:
- Update router firmware to the latest version immediately
- Change default administrative credentials
- Disable remote management if not needed
- Enable router security features and monitor for unusual network activity

## 受影響系統

- ASUS routers (multiple models, especially those running unpatched firmware)
- Home and small office networks
- Enterprise environments with ASUS networking equipment
