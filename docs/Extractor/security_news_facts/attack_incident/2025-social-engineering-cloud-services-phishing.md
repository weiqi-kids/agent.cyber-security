# 社交工程手法再升級：結合雲端服務與短期憑證規避防禦

| 信心水準 | 低 |

## 摘要

駭客利用租用的 Microsoft 365 服務與仿冒域名進行社交工程釣魚攻擊，透過偽冒系統通知及 URL Pattern 精準篩選目標，竊取帳號密碼。攻擊分兩波進行，第二波採魚叉式釣魚連續發送通知營造緊迫氛圍。

## 事實內容

TWCERT/CC 接獲外部情資，近期出現結合雲端服務與仿冒網域的社交工程攻擊活動。駭客透過租用 Microsoft 365 服務、註冊近似官方的域名，並申請短期 SSL 憑證，試圖規避郵件與網頁防禦機制。

**第一波攻擊**：
- 透過租用的 Microsoft 365 合法電子郵件帳號，偽冒「Microsoft 帳戶異常登入活動通知」
- 針對企業內部多個目標發動釣魚郵件攻擊
- 利用 URL Pattern 篩選目標，符合規則便顯示客製化釣魚頁面竊取帳號密碼；不符合則轉向官方合法登入頁面

**第二波攻擊**：
- 採魚叉式釣魚手法，針對特定目標「連續」發送多封偽冒「Microsoft 一次性代碼通知」
- 營造目標帳戶正遭多次嘗試登入假象
- 再次寄送偽冒「Microsoft 帳戶異常登入活動通知」，引誘目標點選連結登入帳戶，進而竊取帳號密碼

駭客持續升級社交工程與釣魚攻擊手法，反覆寄送偽冒的 Microsoft 系統通知，企圖製造緊迫氛圍，利用收件人對官方通知的信任與時間壓力，誘使收件人在未充分確認下點擊惡意連結提供帳號密碼，造成帳戶被未授權存取與敏感資料外洩。

**防護措施建議**：
1. 留意可疑電子郵件，注意郵件來源正確性，不點擊不明的網址或連結，進入可疑網站不輸入個資、帳號密碼及金融資訊
2. 定期更換符合複雜性需求之密碼，並啟用多因子認證 (MFA)，以提高安全防護措施
3. 網路管理人員應參考最新受駭偵測指標，確實實施預防性阻擋措施，以攔截並過濾可疑郵件
4. 加強內部宣導，提升人員資安意識，以防範駭客利用電子郵件進行社交工程攻擊

## 受影響系統

- Microsoft 365 使用者
- 企業內部電子郵件系統使用者
- 未啟用多因子認證的帳戶
