**Source:** NCSC-FI Security Now!

## Summary

This week discusses phishing attacks involving scammers impersonating banks and malware spread via email. Also provides a refresher on what to take into account when a child receives their first smart device.

## Key Points

- Bank impersonation phishing attacks
- Malware distribution via email
- Smart device security guidance for children
- Public awareness and education focus

## Context

Weekly situational awareness report from NCSC-FI covering current threats and providing security guidance.
