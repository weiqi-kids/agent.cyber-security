## 摘要

Q3 2024 recorded 405,955 compromised IP addresses (historic high), with reports up 4.4% QoQ and 21% YoY, driven by geopolitical conflicts.

## 事實內容

CERT.LV's Q3 2024 activity review reveals unprecedented compromise levels:

**Compromised IP Addresses:**
- 405,955 unique compromised IP addresses (highest level historically)
- Reports increased 4.4% quarter-over-quarter and 21% year-over-year

**Geopolitical Context:**
- "Geopolitical and ideological conflicts continue to be strong drivers of cyber attacks"
- Latvia's support for Ukraine amid Russian invasion maintained elevated cyber threat levels
- Cyber threat level significantly increased since Russian invasion of Ukraine

**Key Threat Trends (Q3 2024 vs. Q3 2023):**

**Largest increases:**
- Compromised devices: +267%
- Fraud: +183%
- Service availability: +158%
- Malicious code: +73%

**Notable decrease:**
- Intrusion attempts (only declining threat category)

**Most Common Threat Types:**
1. Configuration deficiencies
2. Malicious code
3. Service availability issues
4. Fraud

**Legislative Impact:**
- National Cybersecurity Law effective September 1, 2024
- Expanded CERT.LV's mandate
- Increased number of constituent organizations requiring compliance

## 受影響系統

- Compromised IP addresses (record high)
- Devices vulnerable to fraud and malicious code
- Services experiencing availability issues
- Systems with configuration deficiencies
