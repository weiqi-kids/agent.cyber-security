## 摘要

廣泛使用的 3CXDesktopApp 視訊會議軟體安裝包遭植入惡意程式碼，2023 年 3 月 22 日後下載或更新者均受影響。

## 事實內容

According to observations by data security companies, harmful code has been slipped into the installation package of the widely used 3CXDesktopApp video conferencing software. This malicious code is installed onto the user's device during an update or fresh installation. A harmful version of the software has been installed if the download or update took place after 22 March 2023. This is a supply chain attack where the legitimate software distribution channel was compromised to deliver malware to end users.

## 受影響系統

- 3CXDesktopApp (versions downloaded/updated after 22 March 2023)
- Windows and macOS installations
