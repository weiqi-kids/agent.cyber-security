## Summary
Estonia recorded 680 impactful cyber incidents in September 2025, including banking service disruptions affecting Swedbank, SEB, and Luminor, WordPress vulnerability exploitation, and extensive phishing campaigns impersonating Omniva and Telia.

## Description
The Estonian Information System Authority (RIA) documented 680 impactful cyber incidents during September 2025, slightly below the previous six-month average but featuring significant disruptions.

**Banking Disruptions**: Multiple financial institutions experienced service outages due to technical errors rather than security breaches:
- **Swedbank** (Sept 3): Login systems, card payments, and ATMs affected
- **SEB** (Sept 8): Website unavailability and slow loading
- **Luminor** (Sept 8): Visa card payment issues across Baltic countries
- **Swedbank** (Sept 11): Website and payment service interruptions

**Infrastructure Attacks**:
- **Laagri School** (Sept 1): WordPress vulnerability allowed command injection, temporarily blocking website access
- **Elron** (Sept 16 & 25): Ticket sales system and route search functionality outages

**Phishing Campaigns**: Extensive fraud operations targeted Estonian users:
- **Omniva impersonation**: Messages claiming parcels require customs payment
- **Telia impersonation**: Fraudulent invoices directing victims to phishing pages for banking credential theft

RIA analyst Dorel Albin noted fraudsters exploit trust and urgency, advising users to pause before clicking payment links.
