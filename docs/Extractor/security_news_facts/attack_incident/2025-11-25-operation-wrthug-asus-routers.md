## 摘要

SecurityScorecard STRIKE team revealed "Operation WrtHug" — a large-scale campaign exploiting known OS command injection vulnerabilities in ASUS routers, primarily targeting the AiCloud service, to conscript infected devices into a global threat network.

## 事實內容

SecurityScorecard's STRIKE team released a report revealing "Operation WrtHug," a large-scale network operation targeting ASUS routers worldwide.

Operation details:
- **Target**: ASUS routers globally, primarily focusing on the AiCloud service
- **Method**: Exploiting a series of publicly disclosed OS command injection vulnerabilities on ASUS devices
- **Goal**: Converting infected devices into tools for a global network threat campaign
- **Scale**: Large-scale, affecting ASUS brand routers broadly deployed in homes and small offices worldwide

TWCERT/CC issued an emergency alert strongly recommending all ASUS router users to:
1. Immediately update router firmware to the latest version
2. Disable AiCloud if not needed
3. Change default credentials
4. Check for signs of compromise

## 受影響系統

- ASUS routers (models with AiCloud feature, specific vulnerable versions in advisory)
