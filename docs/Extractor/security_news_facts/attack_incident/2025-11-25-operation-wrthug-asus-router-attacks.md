## 摘要

SecurityScorecard STRIKE team disclosed Operation WrtHug, a large-scale attack campaign targeting ASUS routers worldwide via OS command injection vulnerabilities in AiCloud service, converting infected devices into botnet nodes for further attacks.

## 事實內容

SecurityScorecard's STRIKE team published a report disclosing a large-scale cyber operation dubbed "Operation WrtHug."

Key details:
- **Target**: ASUS routers globally (primarily targeting ASUS brand)
- **Attack vector**: AiCloud service vulnerabilities, exploiting known OS command injection (OS command injection) vulnerabilities
- **Goal**: Convert infected devices into tools for global network threat activities (botnet)
- **Scale**: Widespread global targeting of ASUS routers

TWCERT/CC issued an emergency alert strongly recommending all ASUS router users to:
1. Immediately update router firmware to the latest version
2. Disable AiCloud service if not needed
3. Change default passwords
4. Enable firewall and disable unnecessary remote access features

## 受影響系統

- ASUS routers with AiCloud service enabled (specific models targeted in advisory)
