# 駭客偽冒通訊軟體，釣魚攻擊再升級

| 欄位 | 內容 |
|------|------|
| 日期 | 2025-07-21 |
| 來源 | TWCERT/CC |
| 分類 | attack_incident |
| 嚴重程度 | 高 |
| 信心水準 | 低 |

## 摘要

駭客偽冒知名通訊軟體，透過社交工程與SEO偽冒網站散布惡意程式，植入多層次後門竊取個人資料，已有多名使用者受害。

## 事實內容

1. **攻擊時間**：2025年2月至3月間開始，7月持續推出變種版本
2. **攻擊手法**：
   - 駭客組織偽冒知名通訊軟體（如LINE）
   - 透過社交工程手法誘導使用者下載惡意檔案
   - 利用SEO攻擊手法建立偽冒網站
   - 使用多層次封裝後門程式，繞過防護機制與端點偵測工具

3. **惡意程式功能**：
   - 基本後門模組
   - 檔案管理模組
   - 鍵盤側錄模組
   - 遠端控制HVNC模組（可操控隱藏桌面）

4. **影響範圍**：已有多名使用者受害，相關攻擊活動影響範圍廣泛

5. **目前狀態**：
   - 2025年6月版本已能被主流防毒軟體偵測與攔截
   - 7月起駭客持續推出變種版本，攻擊行動未停止

6. **已知偽冒LINE網站**：
   - www[.]lineoe[.]com
   - www[.]linerm[.]com
   - www[.]linecl[.]com
   - www[.]line-tww[.]com

## 受影響系統

- 通訊軟體使用者（特別是LINE使用者）
- 透過非官方管道下載應用程式的使用者
- Windows/Android/iOS等各平台使用者
