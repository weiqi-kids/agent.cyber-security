## 摘要

NCSC-FI 第 47 週報告涵蓋黑色星期五季節性包裹遞送詐騙、Microsoft 365 帳號持續入侵事件，以及 CRA 利益相關者活動資訊。

## 事實內容

NCSC-FI 2025 年第 47 週報告主要內容：

1. **包裹遞送詐騙（季節性高峰）**：黑色星期五等購物旺季期間，包裹遞送詐騙案例特別普遍。攻擊者冒充快遞公司發送釣魚訊息，誘導受害者點擊惡意連結或提供個人資訊
2. **Microsoft 365 帳號入侵更新**：持續追蹤 Microsoft 365 帳號遭入侵事件的最新進展
3. **Critical Code 網路研討會回顧**：回顧近期舉辦的 Critical Code 網路研討會內容
4. **EU 資安資金資訊會議**：提醒讀者報名即將舉辦的歐盟網路安全資金資訊說明會
5. **歐盟委員會 CRA 利益相關者活動**：分享歐盟《網路韌性法案》利益相關者活動資訊
6. **NCSA 客戶調查**：NCSC-FI 針對 NCSA 客戶開放調查，收集未來評估、核准和認證需求
7. **本週惡意軟體回顧 — Shiz**：分析 Shiz 惡意軟體的行為特徵

## 受影響系統

- 黑色星期五購物者（包裹詐騙目標）
- Microsoft 365 用戶（帳號入侵）
- 快遞服務品牌（被詐騙者冒用）
