## 摘要

Interlock 勒索軟體組織針對 Cisco 企業防火牆發動攻擊，利用設備漏洞作為初始入侵點進入企業網路。

## 事實內容

- 威脅行為者：Interlock 勒索軟體組織
- 目標：Cisco 企業防火牆設備（如 ASA、Firepower）
- 攻擊手法：利用 Cisco 防火牆漏洞作為初始存取入口（initial access）
- 成功入侵後橫向移動至企業內部網路，部署勒索軟體
- Interlock 組織同時採用雙重勒索（double extortion）策略，竊取資料後再加密
- 此攻擊模式顯示網路邊界設備正成為勒索軟體攻擊的主要切入點

## 受影響系統

- Cisco ASA（Adaptive Security Appliance）防火牆
- Cisco Firepower 系列設備
- 使用 Cisco 企業防火牆的組織網路
