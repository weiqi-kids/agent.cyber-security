## 摘要

SANS ISC published analysis of a React-based phishing page that uses WebSocket communication for credential exfiltration, representing an evolution in phishing techniques designed to evade detection by security tools.

## 事實內容

- SANS Internet Storm Center analyzed a sophisticated phishing page built using the React JavaScript framework
- The phishing page employs WebSocket communication for credential exfiltration, making detection more difficult
- Using React for phishing represents an evolution from traditional static HTML phishing pages
- WebSocket-based exfiltration bypasses some network security monitoring tools that focus on HTTP/HTTPS traffic
- The technique provides real-time data transmission from victim's browser to attacker infrastructure

## 受影響系統

- End users targeted by sophisticated phishing campaigns
- Organizations relying on traditional network-based phishing detection
