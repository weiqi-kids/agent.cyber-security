## 摘要

NCSC-FI 第 44 週報告涵蓋持續發生的 M365 帳號大規模入侵、利用發票服務的發票詐騙，以及 Nymaim 木馬分析。

## 事實內容

NCSC-FI 2025 年第 44 週報告主要內容：

1. **M365 帳號大規模入侵（持續進行中）**：Microsoft 365 帳號入侵浪潮持續，多家組織受到影響。攻擊者利用各種手法（釣魚、憑證填充等）入侵企業 M365 帳號
2. **發票服務被用於發票詐騙**：犯罪分子正在利用合法的發票服務平台發送欺詐性發票，使詐騙訊息看起來更具可信度，繞過垃圾郵件過濾器
3. **EU 網路安全資金申請開放**：新一輪歐盟網路安全資金申請已開放
4. **EU 網路韌性法案評論機會**：開放對歐盟《網路韌性法案》提出評論的機會
5. **本週惡意軟體回顧 — Nymaim 木馬**：分析 Nymaim 木馬的運作機制，該木馬主要針對 Windows 系統，常被用作後期攻擊的載入器

## 受影響系統

- Microsoft 365 用戶及企業（帳號入侵）
- 企業財務部門（發票詐騙）
- Windows 系統（Nymaim 木馬）
