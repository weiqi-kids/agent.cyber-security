## 摘要

Phishers are generating phishing websites using the Bubble AI-powered web-app builder, likely available through phishing-as-a-service platforms, expanding attack capabilities.

## 事實內容

Kaspersky researchers discovered that phishers have added a new technique to their arsenal: generating phishing websites using the Bubble AI-powered web-app builder. Key findings:

- Bubble is a no-code app builder that uses AI to quickly generate web applications
- Phishers are using it to create convincing phishing decoy sites rapidly
- The tactic is highly likely to be available through one or more phishing-as-a-service (PhaaS) platforms
- Because PhaaS platforms distribute this capability, these decoys are expected to appear in a wide range of attacks
- The broad accessibility means this tactic will proliferate quickly

Attack method: Phishing-as-a-Service (PhaaS) using AI-powered no-code website builders to create convincing decoy pages.

## 受影響系統

- Users targeted by phishing campaigns
- Organizations whose users may be deceived by AI-generated phishing sites
