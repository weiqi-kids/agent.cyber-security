## 摘要

Singapore's Cyber Security Agency revealed that APT actor UNC3886 conducted a sophisticated, targeted campaign against all four major telecommunications operators using zero-day exploits and advanced rootkits, exfiltrating network-related technical data.

## 事實內容

Singapore's Coordinating Minister for National Security disclosed on July 18, 2025, that Advanced Persistent Threat (APT) actor UNC3886 had been detected attacking Singapore's critical infrastructure. Recent investigations revealed the full scope of the campaign.

**Attack Campaign Details:**
- Threat actor: UNC3886 (described as having "deep capabilities")
- Campaign characteristics: Deliberate, targeted, and well-planned
- Target sector: Telecommunications
- Affected entities: All four major Singapore telcos (M1, SIMBA Telecom, Singtel, StarHub)

**Attack Techniques:**

1. Zero-Day Exploitation:
   - Used zero-day exploit to bypass perimeter firewall
   - Gained access to telco networks
   - Exfiltrated small amount of technical data (primarily network-related)
   - Purpose: Advance threat actors' operational objectives

2. Advanced Persistence Methods:
   - Deployed rootkits for persistent access
   - Implemented techniques to cover tracks and evade detection
   - Made detection challenging for cyber defenders
   - Required comprehensive security checks across networks

**Response:**
- Largest multi-agency cyber operation mounted in Singapore
- Coordinated by Cyber Security Agency (CSA)
- Comprehensive security checks conducted across telecommunications networks

**APT Characteristics:**
- Sophisticated and persistent threat actor
- Advanced methods to bypass defenses over time
- Deep technical capabilities
- Advanced tools deployment

## 受影響系統

- M1 telecommunications infrastructure
- SIMBA Telecom telecommunications infrastructure
- Singtel telecommunications infrastructure
- StarHub telecommunications infrastructure
