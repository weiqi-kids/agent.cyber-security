## 摘要

NCSC-FI 第 45 週報告彙整攻擊者近期針對一般公民的詐騙與釣魚手法，目標為金錢與個人資訊，並記錄 Cyber Security Nordic 展會動態。

## 事實內容

NCSC-FI 2025 年第 45 週報告主要內容：

1. **針對公民的攻擊手法彙整**：本週報告重點介紹攻擊者近期最常用來欺騙普通公民的方式，主要目標為：
   - **金錢**：透過詐騙誘導受害者轉帳或提供支付資訊
   - **資訊**：竊取個人身份資訊、帳號憑證等敏感資料
2. **詐騙和釣魚訊息的多樣性**：詐騙和釣魚訊息的種類範圍廣泛，NCSC-FI 提醒民眾應保持警覺，仔細檢視收到的新訊息
3. **Cyber Security Nordic 展會**：本週舉辦 Cyber Security Nordic 資安展覽，NCSC-FI 亦出席參與

## 受影響系統

- 一般公民（詐騙與釣魚目標）
- 金融服務用戶（金融詐騙目標）
