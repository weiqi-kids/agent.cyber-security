# 新興區塊鏈 C2 威脅浮現,「EtherHide」成駭客新寵

## 摘要
攻擊者利用「EtherHide」技術將惡意指令寫入區塊鏈智能合約,搭配「ClearFake」假更新手法,繞過傳統網路防禦機制,形成難以封鎖的C2通道。

## 事實內容

### 攻擊技術特徵
- **EtherHide技術**: 利用區塊鏈去中心化、不可篡改及匿名性特性,將C2惡意指令或惡意酬載地址寫入智能合約
- **ClearFake手法**: 以社交工程為核心,在受感染WordPress網站植入惡意JavaScript,彈出偽裝系統通知或軟體更新訊息
- **首次發現時間**: EtherHide於2023年10月首次被提出,ClearFake於2023年第2季被發現
- **主要平台**: BSC(Binance Smart Chain)智能鏈

### 攻擊流程
1. 攻擊者入侵存在漏洞的WordPress網站取得控制權
2. 在網站頁面植入惡意JavaScript程式碼
3. 使用者瀏覽受感染網站時自動執行惡意程式碼
4. 彈出偽冒更新訊息(ClearFake)誘騙使用者點擊
5. 連線至BSC智能合約,透過EtherHide技術取得惡意指令或酬載位置
6. 下載並部署下一階段惡意程式至受害者電腦
7. 惡意程式啟動並執行攻擊行為

### 技術特點
- 使用幣安SDK的「eth_call」方法讀取智能合約
- 無需支付交易費用(gas)且不留區塊鏈紀錄
- 傳統追蹤技術不易套用
- 區塊鏈上資料不可刪除,惡意指令無法下架
- 降低在受害者端部署大量檔案的偵測風險

### 防禦建議
1. 確保WordPress等CMS核心與外掛隨時更新,搭配WAF防護
2. 部署端點防護系統、動態行為分析與沙箱技術
3. 定期進行社交工程演練提升員工警覺性
4. 敏感系統與公共鏈互動時規劃白名單或存取控制機制
5. 將EtherHide納入行為偵測模型與威脅情報資料庫

## 受影響系統
- WordPress網站及其外掛系統
- 與BSC(Binance Smart Chain)節點或RPC介面互動的系統
- Windows/macOS等終端使用者系統(透過瀏覽器感染)
