## Summary

Pakistan-based APT36 (Transparent Tribe) adopts AI-driven "vibeware" malware development using niche languages (Nim, Zig, Crystal) and trusted cloud services for C2.

## Factual Content

Bitdefender research reveals that Pakistan-based threat actor APT36, also known as Transparent Tribe, has pivoted from off-the-shelf malware to "vibeware" — an AI-driven development model that produces high-volume, mediocre-quality implants. Key characteristics:

- **Niche programming languages**: Uses Nim, Zig, and Crystal to evade standard detection engines.
- **Cloud-based C2**: Leverages trusted cloud services including Slack, Discord, Supabase, and Google Sheets for command and control.
- **AI-driven development**: The "vibeware" model uses AI to rapidly produce malware variants at scale, prioritizing volume over sophistication.

## Affected Systems

- Targets not specified in the RSS description (APT36 historically targets Indian government and military)
- Detection engines for standard malware (evasion via niche languages)
- Cloud services: Slack, Discord, Supabase, Google Sheets (abused for C2)
