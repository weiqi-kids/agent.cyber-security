# Facebook 2019 data breach published - 1.2M Finns affected

**Source**: NCSC-FI (Finland)  
**Link**: https://www.kyberturvallisuuskeskus.fi/en/news/data-stolen-facebook-2019-published-includes-information-12-million-finns  
**Published**: 2021-05-07

## Summary

Data stolen from Facebook in 2019 was published on an online hacker forum, including information on 533 million people globally, with 1.2 million Finnish users affected. The same data was offered for sale via Telegram bot in January 2021.

## Key Points

- **Incident date**: 2019 breach
- **Publication date**: April 2021
- **Total affected**: 533 million people globally
- **Finnish users**: 1.2 million
- **Distribution**: Posted on hacker forum
- **Prior activity**: Sale attempts via Telegram in January 2021

## Impact

The delayed publication of old breach data demonstrates that stolen information retains value for years. Finnish users represent significant portion of exposed data enabling targeted social engineering.
