# 提高社交工程警覺！偽冒主管要求建群組與提供個資

## 摘要
攻擊者偽冒企業主管發送社交工程郵件，誘騙員工建立LINE群組、提供QR Code及員工個資清單。

## 事實內容
TWCERT/CC近期接獲多筆外部情資，發現攻擊者透過偽冒企業內部主管名義發起社交工程攻擊。攻擊手法特徵包括：

**攻擊手法：**
- 偽冒公司主管身份發送電子郵件
- 以「主管指示」、「行政需求」、「緊急任務」為切入點
- 要求員工執行特定操作

**攻擊目標：**
1. 要求建立公司內部LINE群組，並回傳群組QR Code
2. 要求提供員工清單個資資訊

**防範建議：**
- 確認郵件來源正確性，避免點擊可疑附件或連結
- 向主管或資訊部門確認郵件真實性
- 定期更換密碼並啟用多因子認證(MFA)
- 部署預防性阻擋措施攔截可疑郵件
- 加強內部資安宣導與演練

## 受影響系統
- 企業電子郵件系統
- LINE通訊軟體
- 人員個資系統
