## 摘要

Slovakia's NCSC warns of Oracle Cloud infrastructure compromise affecting essential service operators, with 6 million user account records stolen.

## 事實內容

Slovakia's National Cybersecurity Centre warns of possible compromise of Oracle's cloud infrastructure with impact on essential service operators in Slovakia. On March 21, 2025, a security incident was recorded where an unknown attacker nicknamed rose87168 reported gaining access to Oracle Cloud federated authentication servers and stealing approximately 6 million user account records. The breach has implications for Slovak organizations using Oracle Cloud services.

## 攻擊手法

- Unauthorized access to Oracle Cloud federated authentication servers
- Large-scale user account data exfiltration

## 受影響系統

- Oracle Cloud infrastructure
- Oracle Cloud federated authentication servers
- Slovak essential service operators using Oracle Cloud
