## 摘要

NCSC-FI's week 36/2025 review reports financial losses from child protection-themed scam messages, highlights Microsoft's new authentication methods, presents weekly malware review, and invites participation in Critical Code webinar.

## 事實內容

The National Cyber Security Centre Finland (NCSC-FI) published its weekly review for week 36 of 2025, covering scam campaigns and security improvements.

**Active Threat Campaigns:**

1. Child Protection-Themed Scam Messages:
   - Method: Messages impersonating child protection services
   - Objective: Financial fraud
   - Impact: Financial losses reported
   - Exploitation: Sensitive topic to create urgency and fear
   - Victims: Parents and guardians

**Security Improvements:**

2. Microsoft Authentication Methods:
   - Microsoft introducing new authentication methods
   - Enhancement of account security features
   - Improved protection against account compromise
   - Relevant to ongoing M365 breach campaign context

**Educational Content:**
- Weekly malware review presented
- Technical analysis for security professionals

**Industry Events:**

3. Critical Code Webinar:
   - Invitation to participate
   - Focus: Software security
   - Target audience: Developers and security professionals

**Significance:**
- Social engineering exploiting child safety concerns
- Financial impact on victims
- Positive security developments (Microsoft authentication)
- Continued education and industry engagement

## 受影響系統

- Messaging platforms (scam message delivery)
- Banking systems (financial fraud targets)
- Microsoft 365 accounts (authentication improvements)
