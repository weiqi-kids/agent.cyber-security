## 摘要

JPCERT confirmed incidents from Sept-Dec 2024 involving CrossC2 extension tool for creating Cobalt Strike Beacon on Linux OS.

## 事實內容

From September to December 2024, JPCERT/CC has confirmed incidents involving CrossC2, the extension tool to create Cobalt Strike Beacon for Linux OS. The attacker employed CrossC2 as well as other tools such as PsExec, Plink, and Cobalt Strike in attempts to expand their attack capabilities across different platforms.

CrossC2 extends the capabilities of Cobalt Strike beyond Windows systems, allowing attackers to compromise Linux environments using the same command and control framework. This represents a significant evolution in cross-platform attack methodologies.

## 受影響系統

- Linux operating systems
- Windows systems running Cobalt Strike
- Organizations using mixed OS environments
