# New ID Card Requires ID Software Update

| Item | Content |
|------|---------|
| **Date** | 2025-07-25 |
| **Source** | CERT-EE (Estonia) |
| **Category** | policy_regulation |
| **Severity** | info |
| **Confidence** | high |

## Summary
Users receiving new Estonian ID cards after July 2025 must update ID software to version 25.5 (macOS/Ubuntu) or 25.6 (Windows) for electronic functionality.

## Facts Content
**Effective Date**: July 2025 (beginning)
**Card Manufacturer**: IDEMIA
**Change**: New chip platform for Estonian ID cards

**Required Software Versions**:
- macOS: Version 25.5
- Ubuntu: Version 25.5
- Windows: Version 25.6

**Affected Functions**:
- Electronic authentication
- Digital signature functionality
- All ID card electronic services

**Target Users**: Anyone receiving ID card issued after early July 2025

**Official Source**: Information System Authority (RIA) of Estonia

**Notes**:
- Original language: Estonian
- Critical for maintaining electronic ID functionality
- Users with old cards unaffected
- Part of national digital ID infrastructure modernization
