## Summary
Estonian authorities remind citizens to verify ID document validity and PIN code availability before February 15 tax declaration period begins.

## Facts Content
**Reminder Issuers**:
- Tax and Customs Board (MTA)
- Police and Border Guard Board (PPA)
- Information System Authority (RIA)

**Tax Declaration Start**: February 15, 2025

**Pre-Declaration Checklist**:
- Verify document validity period
- Confirm PIN code availability
- Ensure digital authentication capabilities

**Purpose**: Prevent technical issues during tax declaration period

**Context**: Annual income tax declaration in Estonia done electronically

**Notes**:
- Original language: Estonian
- Proactive user education
- Critical for e-government service access
- Estonia's tax system heavily digitized
