## Summary
Estonia's Electoral Commission decides to create e-voting application for autumn local government elections supporting Windows, macOS, and Linux computers.

## Facts Content
**Decision Maker**: Republic Electoral Commission (Vabariigi Valimiskomisjon)
**Election Type**: Local government council elections
**E-Voting Platform**: Computer-based e-voting application

**Supported Operating Systems**:
- Windows
- macOS
- Linux

**Implementation Approach**:
- Similar to previous elections
- Dedicated voter application for computers
- Established e-voting infrastructure continuation

**Notes**:
- Original language: Estonian
- Estonia pioneered nationwide internet voting in 2005
- Demonstrates continued commitment to digital democracy
- Computer-based approach (mobile voting still in testing phase)
