## 摘要

Estonia's RIA clarifies that e-service providers must ensure compatibility with new ID cards (issued from November 2025); users experiencing errors should contact the service provider first.

## 事實內容

The Estonian Information System Authority (RIA) clarified that with the introduction of new ID cards issued since November 17, 2025, e-service providers are responsible for ensuring their systems and software are compatible with the new cards' technical specifications. If a user encounters errors when using the new ID card in an e-service, they should first contact the respective service provider, who can analyse the problem in more detail and involve RIA if necessary. This advisory outlines the responsibility framework for managing compatibility issues with the new generation of Estonian ID cards.

## 受影響系統

- Estonian ID cards (issued from November 17, 2025)
- Estonian e-services
- DigiDoc4 and other authentication software
