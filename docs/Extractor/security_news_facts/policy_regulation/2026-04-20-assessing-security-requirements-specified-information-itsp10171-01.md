## 摘要

Canadian Centre for Cyber Security releases ITSP.10.171-01 practitioner guidance for assessing security requirements for specified information in government and critical systems.

## 事實內容

The Canadian Centre for Cyber Security (Cyber Centre) published ITSP.10.171-01 (April 2026), a practitioner-series document addressing how to assess security requirements for specified information.

Key points:
- This is an UNCLASSIFIED publication issued under the authority of the Head of the Canadian Centre for Cyber Security.
- Contact information: contact@cyber.gc.ca or (613) 949-7048 / 1-833-CYBER-88.
- The document provides a framework for practitioners to evaluate security classification requirements for sensitive government and organizational information.
- Intended audience: Security practitioners, information managers, and government IT professionals responsible for handling designated/specified information.
- The publication is part of the Cyber Centre's practitioner series, providing detailed technical and procedural guidance.
- A PDF alternate format is also available.

## 受影響系統

- Government of Canada information management systems
- Organizations handling classified or specified information
- Security practitioners and information security programs
