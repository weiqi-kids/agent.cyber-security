## Summary
Estonian Information System Authority confirms Estonia's e-voting system is secure, transparent, and continuously developed.

## Description
The Estonian Information System Authority (RIA) confirms that Estonia's e-voting system is secure, transparent, and continuously developed. This statement reassures stakeholders about the integrity of Estonia's pioneering electronic voting infrastructure, which has been in use for national elections since 2005.
