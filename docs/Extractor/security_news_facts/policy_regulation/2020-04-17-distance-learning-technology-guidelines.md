## Summary

CNCS publishes security guidelines for distance learning platforms (ZOOM, Moodle, Microsoft Teams, Google Classroom) for educational community.

## Factual Content

These measures are specifically intended for audio and video communication platforms directed at the educational community, such as ZOOM, Moodle, Microsoft Teams, and Google Classroom. The objective of these guidelines, which arise in the context of distance learning, is to ensure that the configuration and use of these platforms is done securely. The guidelines provide recommendations for secure configuration and usage of distance learning platforms.

## Affected Systems

- ZOOM
- Moodle
- Microsoft Teams
- Google Classroom
