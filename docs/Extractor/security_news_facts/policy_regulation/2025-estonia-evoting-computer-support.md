## Summary
National Electoral Committee decided to create e-voting application for local government elections on Windows, MacOS, and Linux operating systems, similar to previous elections.

## Description
The National Electoral Committee decided that for the local government council elections, an e-voting application will be created for computer operating systems Windows, MacOS, and Linux, similar to previous elections. This ensures voters can use traditional computer-based e-voting methods in addition to any new mobile voting options being tested.

## Technical Details
- **Election**: Local government council elections (autumn)
- **Platforms**: Windows, MacOS, Linux
- **Decision Body**: National Electoral Committee
- **Approach**: Similar to previous elections
