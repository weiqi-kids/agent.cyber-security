# G7 Cybersecurity Working Group Statement on Post-Quantum Cryptography Migration

## 摘要

G7 網路安全工作組聯合發表聲明，呼籲各組織開始規劃後量子密碼學遷移，以應對量子運算對現有加密標準的潛在威脅。

## 事實內容

G7 網路安全工作組聯合聲明，由加拿大 CSE、德國 BSI、義大利 ACN、法國 ANSSI、日本 NPA/MIC/METI/MEXT、英國 NCSC、美國 CISA/NSA/NIST 共同發布。

**主要內容**：
- 量子運算技術進步對現有公鑰加密標準（RSA、ECC 等）構成長期威脅。
- 呼籲組織立即開始密碼學敏捷性（cryptographic agility）規劃。
- 建議採用 NIST 後量子密碼學標準（FIPS 203、FIPS 204、FIPS 205）。
- 遷移路線圖應包含：資產盤點、優先級排序、混合加密過渡方案。
- 特別強調「現在收集、未來解密」（Harvest Now, Decrypt Later）攻擊的風險。

**建議行動**：
1. 建立密碼學資產清單
2. 評估量子風險暴露程度
3. 制定後量子遷移計畫
4. 測試並部署後量子演算法

## 受影響系統

- 使用 RSA/ECC 加密的所有系統
- PKI 基礎設施
- TLS/SSL 通訊
- 數位簽章系統
- VPN 及加密通訊協定
