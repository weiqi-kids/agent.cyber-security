# National Cybersecurity Reference Framework Now Available

**Date:** 2019-06-26
**Source:** CNCS (Portugal)
**Link:** [https://dyn.cncs.gov.pt/pt/detalhe/art/529/o-quadro-nacional-de-referencia-para-a-ciberseguranca-ja-se-encontra-disponivel](https://dyn.cncs.gov.pt/pt/detalhe/art/529/o-quadro-nacional-de-referencia-para-a-ciberseguranca-ja-se-encontra-disponivel)

## Summary

Portugal's CNCS has released the National Cybersecurity Reference Framework to help organizations implement measures against cyber threats and establish comprehensive security strategies.

## Details

The document reflects the Portuguese organizational reality, responding to the need to implement measures against threats that compromise cyberspace security. This document provides a set of recommendations for organizations to define a strategy that involves their entire structure. Entities can voluntarily adhere and benefit from a homogeneous approach that promotes a national response to cyber threats.

The framework aims to establish guidelines for organizations to assess and improve their cybersecurity posture through standardized practices aligned with national cybersecurity objectives.
