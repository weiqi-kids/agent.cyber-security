## 摘要
NUKIB publishes updated minimum requirements for cryptographic algorithms to reflect evolving security landscape.

## 事實內容
The National Cyber and Information Security Agency (NÚKIB) of the Czech Republic has released an updated version of its Minimum Requirements for Cryptographic Algorithms document.

**Purpose:**
The document provides binding guidance for cryptographic algorithm selection and implementation for organizations subject to Czech cybersecurity legislation.

**Need for Updates:**
- Security of individual algorithms continuously evolves
- New algorithms are developed
- New attacks on existing algorithms may be discovered
- Document must reflect current knowledge in cryptographic field

**Legal Framework:**
According to Section 26(d) of Decree No. 82/2018 Coll. on security measures, mandatory entities under Act No. 181/2014 Coll. on cyber security must consider these recommendations for protecting information and communication system assets.

**Scope:**
The requirements cover:
- Minimum cryptographic algorithm strengths
- Approved encryption standards
- Key length requirements
- Hash function specifications
- Digital signature algorithms

**Continuous Process:**
NUKIB emphasizes that regular updates are necessary to maintain effective cryptographic protection against evolving threats and computational capabilities.

This update ensures Czech organizations maintain strong cryptographic practices aligned with current security standards.
