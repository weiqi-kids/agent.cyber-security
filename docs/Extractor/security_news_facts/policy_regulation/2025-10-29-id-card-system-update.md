# RIA: Service Providers Must Prepare IT Systems for New ID Cards

## Summary
RIA reminds service providers to update IT systems before November 14, 2025 for new ID cards from Thales replacing IDEMIA, or electronic functionality will fail.

## Factual Content
New ID cards will be introduced on November 14, 2025, when Thales will start producing ID cards instead of the previous manufacturer IDEMIA. RIA reminds service providers that their IT systems must be updated before this date. If updates are not made, electronic use of new ID cards will not be possible in the service provider's systems, and client card functionality will not work.

**Critical Details:**
- Launch date: November 14, 2025
- New manufacturer: Thales (replacing IDEMIA)
- Action required: IT system updates
- Deadline: Before November 14, 2025
- Impact if not updated: Electronic functionality failure, client card features disabled
- Target audience: Service providers
