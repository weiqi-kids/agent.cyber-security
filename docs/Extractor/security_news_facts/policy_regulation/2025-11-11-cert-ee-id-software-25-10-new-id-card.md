## 摘要

Estonia's RIA released ID software version 25.10 supporting the new Thales-manufactured ID card to be introduced in November's second half, bringing changes to the card's appearance, chip, and software.

## 事實內容

The Estonian Information System Authority (RIA) released a new version (25.10) of the ID software that supports the new ID card to be rolled out in the second half of November 2025. The new ID card (manufactured by Thales, replacing previous manufacturer IDEMIA) brings changes to both the card's appearance and its chip technology. Users need to update their ID software to use the new card. This represented a significant transition in Estonia's national identity card infrastructure, with implications for all digital services relying on Estonian ID card authentication.

## 受影響系統

- Estonian ID card (new Thales model)
- ID software (DigiDoc4 and related applications)
- All Estonian e-services using ID card authentication
