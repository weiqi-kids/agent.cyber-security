## 摘要
NUKIB publishes updated version 3.0 of cryptographic tools recommendations for entities under Czech cybersecurity law.

## 事實內容
The National Cyber and Information Security Agency (NÚKIB) of the Czech Republic has released an updated version of its document containing recommendations for cryptographic tools.

**Legal Framework:**
According to Section 26(d) of Decree No. 82/2018 Coll. on security measures, cybersecurity incidents, reactive measures, requirements for submissions in the field of cybersecurity, and data disposal:

**Mandatory Compliance:**
Obligated entities under Act No. 181/2014 Coll. on Cyber Security and related legislation amendments must consider NÚKIB's cryptographic tool recommendations for the purpose of protecting information and communication system assets.

**Document Purpose:**
The recommendations provide guidance on:
- Selection of appropriate cryptographic tools
- Implementation of cryptographic controls
- Protection of information system assets
- Compliance with cybersecurity legislation

**Version 3.0 Updates:**
This represents a significant update to the cryptographic tools guidance, reflecting:
- Current cryptographic standards
- Evolving threat landscape
- New tool capabilities
- Updated best practices

**Target Audience:**
- Organizations subject to Czech Cyber Security Act
- Information security professionals
- System administrators
- Compliance officers

The document serves as authoritative guidance for implementing cryptographic controls in Czech organizations under cybersecurity regulations.
