## 摘要

EU project CYSSDE (CyberSecurity Deployment Preparedness Support, Capacity and Capabilities) open call running until 7 April for penetration testing and vulnerability analysis funding.

## 事實內容

An open call from the European project CYSSDE — CyberSecurity Deployment Preparedness Support, Capacity and Capabilities — is running until 7 April 2025. The project aims to finance and provide support for:

- Cybersecurity penetration testing
- Vulnerability analysis
- Building cybersecurity deployment preparedness capacity and capabilities

The initiative is designed to strengthen cybersecurity preparedness across participating organizations and member states.

## 受影響系統

- Organizations seeking cybersecurity penetration testing support
- EU member state entities
