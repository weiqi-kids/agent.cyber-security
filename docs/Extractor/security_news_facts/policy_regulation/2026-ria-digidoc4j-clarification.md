## Summary
RIA clarifies that earlier warning about digital signature functionality issues from February 4 is no longer relevant, as SK ID Solutions will implement 3072-bit RSA keys.

## Factual Content
The Information System Authority (RIA) clarifies that previous information about possible digital signature malfunction starting from February 4 is no longer relevant. Digital signatures will continue to work because SK ID Solutions will implement 3072-bit RSA keys for signing validity confirmations.

**Key Points:**
- Previous warning: Digital signature issues expected from February 4
- Current status: Issue resolved
- Solution: SK ID Solutions implementing 3072-bit RSA keys
- Impact: Digital signatures will continue functioning normally
