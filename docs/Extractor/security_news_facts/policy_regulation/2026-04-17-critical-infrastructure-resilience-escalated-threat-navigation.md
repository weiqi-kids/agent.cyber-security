## 摘要

Canadian Centre for Cyber Security launches Critical Infrastructure Resilience and Escalated Threat Navigation initiative, urging organizations to strengthen cyber readiness amid heightened threat environment.

## 事實內容

The Canadian Centre for Cyber Security published the Critical Infrastructure Resilience and Escalated Threat Navigation (CIRETAN) initiative page (April 2026).

Key points:
- Tagline: "The time to act is now: Strengthening critical infrastructure cyber readiness for a resilient Canada."
- The initiative is part of the Cyber Centre's "cyber security readiness" program for Canadian critical infrastructure operators.
- The initiative was launched alongside a press release calling on critical infrastructure operators to prepare for severe cyber threats.
- The program is designed to navigate an escalated threat environment and provide guidance and resources for resilience building.

Note: Description was brief (101 characters); the initiative page itself provides full program details at the source URL.

## 受影響系統

- Canadian critical infrastructure operators
- Government of Canada security programs
