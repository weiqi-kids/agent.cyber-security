# First companies granted information security development support

## Summary
Traficom has granted information security development support to first companies. Application processing is ongoing, with later applicants facing longer wait times for decisions.

## Key Details
- **Authority**: Traficom (Finnish Transport and Communications Agency)
- **Program**: Information security development support
- **Status**: First recipients announced
- **Timeline**: Processing ongoing, later applications pending

## Context
This represents early implementation of Finland's information security support program for companies.

## Notes
- Grant program implementation
- Phased rollout
- Confidence: high
