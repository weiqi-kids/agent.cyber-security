## 摘要

NUKIB (Czech national cybersecurity authority) published a new support document—"Guide to Documenting Requirements for Cloud Computing Service Catalogue Registration"—to help cloud service providers understand and comply with registration requirements under Czech Decree No. 505/2025 Sb.

## 事實內容

- NUKIB published the "Guide to Documenting Requirements for Cloud Computing Service Catalogue Registration" (Průvodce dokládání požadavků pro zápis služby cloud computingu).
- The guide is intended for cloud computing service providers seeking registration in the Czech national cloud computing catalogue.
- It helps providers navigate requirements set out in Czech Decree No. 505/2025 Sb. (on certain requirements for registration in the cloud computing catalogue).
- The guide assists in preparing complete documentation for cloud service registration applications.
- Announcement published on 2026-04-20.
- NUKIB (Národní úřad pro kybernetickou a informační bezpečnost) is the Czech national cybersecurity and information security authority.

## 受影響系統

- Cloud computing service providers operating in or seeking registration in the Czech national cloud catalogue
