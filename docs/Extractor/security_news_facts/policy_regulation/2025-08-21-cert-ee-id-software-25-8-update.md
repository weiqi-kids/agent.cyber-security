## 摘要

Estonia's RIA released ID software version 25.8 to ensure system functionality and add security features; all users are recommended to update to the latest version.

## 事實內容

The Estonian Information System Authority (RIA) released a new version (25.8) of the Estonian ID software to ensure systems continue to function properly and to add additional security features. All users are recommended to update their ID software to the latest version. Regular updates to Estonia's ID software are critical for maintaining the security and functionality of the country's digital identity infrastructure, which underpins a wide range of government and private sector services.

## 受影響系統

- Estonian ID software (ID card, Mobile-ID, Smart-ID tools)
- All users of Estonian digital identity services
