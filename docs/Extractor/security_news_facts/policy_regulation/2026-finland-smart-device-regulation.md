# Regulation to make smart devices more secure from August 2024

## Summary
Starting August 1, 2024, devices not meeting information security requirements can be withdrawn from the Finnish market. Manufacturers, importers and vendors must immediately ensure products are sufficiently secure.

## Key Details
- **Effective Date**: August 1, 2024
- **Scope**: Smart devices sold in Finland
- **Requirement**: Information security standards compliance
- **Enforcement**: Market withdrawal for non-compliant devices
- **Action Required**: Immediate preparation by manufacturers/importers/vendors

## Context
This regulatory measure addresses consumer IoT security concerns by establishing enforceable minimum security standards.
