## Summary
Estonia's Information System Authority releases ID software version 25.5 with support for new chip platform ID cards.

## Facts Content
**Release Date**: June 20, 2025
**Software**: ID software version 25.5
**Publisher**: Information System Authority (RIA) of Estonia

**Key Update**:
- Added support for new ID cards
- Required for new chip platform cards
- Enables compatibility with updated card technology

**Affected Users**:
- Recipients of new ID cards (issued after July 2025)
- All ID software users on supported platforms
- Electronic authentication and signature users

**Technical Impact**:
- Required for electronic authentication with new cards
- Required for digital signatures with new cards
- Backward compatible with existing card infrastructure

**Notes**:
- Original language: Estonian
- Critical infrastructure update
- Part of national digital ID modernization
- Proactive release before mass card issuance
