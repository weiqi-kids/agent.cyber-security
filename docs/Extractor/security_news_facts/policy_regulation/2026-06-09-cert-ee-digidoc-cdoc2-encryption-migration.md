## 摘要

Estonia's RIA will migrate DigiDoc application to new CDOC2 encryption format in autumn 2026, replacing the older CDOC1 format to enhance security and reliability of encrypted data.

## 事實內容

- **Organization**: Riigi Infosüsteemi Amet (RIA) — Estonia's State Information System Authority
- **Change**: DigiDoc application will transition to CDOC2 (new encryption format) in autumn 2026
- **Current format**: CDOC1 (being phased out)
- **New format**: CDOC2 — provides increased security and reliability for encrypted data
- **Timeline**: Autumn 2026
- **Impact**: E-service providers notified to prepare for the format transition
- **Purpose**: Standards upgrade to improve security of digitally signed/encrypted documents

## 受影響系統

- DigiDoc application (Estonia)
- E-service providers relying on CDOC1 encryption format
- All organizations processing Estonian digitally encrypted documents
