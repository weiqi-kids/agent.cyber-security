## 摘要

Canadian Centre for Cyber Security publishes ITSAP.30.033 guidance on security considerations for passkeys, a phishing-resistant authentication mechanism organizations should evaluate carefully.

## 事實內容

The Canadian Centre for Cyber Security released ITSAP.30.033 (April 2026) addressing cyber security considerations for passkeys.

Key points from the RSS description:
- Passkeys provide a strong and phishing-resistant authentication mechanism.
- Despite their security strengths, there are several security considerations that organizations should be aware of before adopting passkeys.
- The publication is part of the Cyber Centre's awareness series, aimed at helping organizations make informed decisions about authentication technology.
