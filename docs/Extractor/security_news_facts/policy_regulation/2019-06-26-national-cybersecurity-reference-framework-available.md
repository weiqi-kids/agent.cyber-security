## Summary

Portugal's National Cybersecurity Reference Framework has been published, providing recommendations for organizations to implement cybersecurity measures.

## Factual Content

The Portuguese National Cybersecurity Reference Framework (QNRCS) has been released, reflecting the organizational reality in Portugal and addressing the need to implement measures against cyber threats. The document provides a set of recommendations for organizations to define a comprehensive cybersecurity strategy involving their entire structure. Entities can voluntarily adopt this framework and benefit from a homogeneous approach that promotes a national response to cyber threats.

## Affected Systems
