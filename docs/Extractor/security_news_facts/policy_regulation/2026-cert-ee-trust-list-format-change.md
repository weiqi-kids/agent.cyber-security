## Summary
Estonia's trust list upgrade from version 5 to version 6 requires all information systems and software solutions that create or validate digital signatures to update.

## Facts Content
**Change**: Trust list format upgrade
**Version**: From version 5 to version 6
**Impact**: Systems creating or validating digital signatures

**Required Actions**:
- Check all information systems using digital signatures
- Verify new format support
- Update software solutions if necessary
- Prevent digital signature validation errors

**Affected Systems**:
- Digital signature creation systems
- Digital signature validation systems
- All software handling trust lists
- PKI infrastructure components

**Timeline**: Update required to avoid service disruption

**Issuer**: Information System Authority (RIA) of Estonia

**Notes**:
- Original language: Estonian
- Critical infrastructure update
- Impacts Estonian digital signature ecosystem
- Requires proactive action by system operators
