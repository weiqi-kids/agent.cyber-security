## 摘要

NCSC 發布供應商安全評估指引，協助英國公共電信業者依《電信安全法 2021》評估網路設備供應商的安全流程與設備風險。

## 事實內容

UK NCSC 於 2022-03-22 發布供應商安全評估（Vendor Security Assessment）指引（2025 年 3 月更新）：

- 指引協助公共電信業者依《電信安全法（Telecommunications Security Act）2021》合規，客觀評估使用供應商設備所帶來的網路風險
- 提供可重複、客觀的證據收集方法，評估供應商安全流程及網路設備性能
- 引用於電信安全法實務守則（Telecom Security Act Code of Practice）
- 適用對象：中小型組織、大型企業及資安專業人員
- 以 PDF 技術報告形式發布（352.55 KB），與英國主要電信業者協作編制

## 受影響系統

- 英國電信業者使用的網路設備
- 電信供應商安全評估流程
- 國家電信基礎設施
