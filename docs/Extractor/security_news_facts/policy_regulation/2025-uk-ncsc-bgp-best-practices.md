## 摘要

NCSC publishes technical best practices for Border Gateway Protocol (BGP) usage among Internet Service Providers to improve routing security.

## 事實內容

The UK National Cyber Security Centre released a technical report on responsible use of the Border Gateway Protocol (BGP) for ISP interworking. The report:

- Provides best practice guidance for BGP configuration and operation
- Addresses BGP security vulnerabilities including route hijacking and leaks
- Recommends technical controls to improve routing security
- Supports efforts to secure fundamental internet routing infrastructure

BGP is the core protocol that routes traffic across the internet, but its design lacks built-in security mechanisms. Misconfigurations or malicious BGP announcements can redirect internet traffic, causing outages or enabling interception. This technical guidance helps ISPs implement security controls to reduce these risks.

## 受影響系統

- Internet Service Provider networks
- BGP routing infrastructure
- Internet backbone systems
