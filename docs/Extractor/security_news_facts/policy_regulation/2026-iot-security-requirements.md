# IoT device security requirements and Cybersecurity Label

**Source**: NCSC-FI (Finland)  
**Link**: https://www.kyberturvallisuuskeskus.fi/en/news/information-security-requirements-smart-devices-are-companies-ready  
**Published**: 2021-05-26

## Summary

Information security of smart devices raises questions for manufacturers, retailers and consumers. Finland introduced voluntary Cybersecurity Label for secure smart devices in late 2019. EU-level voluntary and mandatory requirements are under discussion.

## Key Points

- **Finnish initiative**: Cybersecurity Label introduced late 2019
- **Type**: Voluntary security label for IoT devices
- **EU developments**: Discussion of voluntary and mandatory requirements
- **Stakeholders**: Manufacturers, retailers, consumers
- **Objective**: Improve IoT device security through standards

## Impact

Cybersecurity labeling helps consumers make informed security decisions. Finland's early voluntary program positions the country for EU-wide IoT security standards.
