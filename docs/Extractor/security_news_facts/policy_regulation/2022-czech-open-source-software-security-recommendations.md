## 摘要

Czech NUKIB and Ministry of Interior published security recommendations for open source software development.

## 事實內容

The Czech National Cyber and Information Security Agency (NÚKIB) in cooperation with the Ministry of Interior (MV) prepared security recommendations for open source software development. The recommendations are intended for developers and individuals engaged in cybersecurity or companies supplying software. It does not replace the requirements of the Cybersecurity Act and is not strictly binding. It is up to specific organizations to decide which parts and to what extent they will use in their projects.

## 受影響系統

- Open source software developers
- Software vendors in Czech Republic
