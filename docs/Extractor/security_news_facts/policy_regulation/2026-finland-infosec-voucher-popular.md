# Information security voucher program hugely popular, applications exceed funding

## Summary
Traficom's information security voucher program (support for information security development) has been accepting applications since early December. Applications already exceed available funding.

## Key Details
- **Program**: Information security vouchers (development support)
- **Authority**: Traficom
- **Start**: Early December 2022
- **Status**: Applications exceed funding
- **Popularity**: Hugely popular

## Context
High demand demonstrates strong organizational interest in improving cybersecurity capabilities with government support.

- Market demand indicator
