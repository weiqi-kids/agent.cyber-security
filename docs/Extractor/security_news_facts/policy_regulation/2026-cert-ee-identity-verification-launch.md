## Summary
Estonia announces July 7, 2025 launch of new identity verification feature in national mobile app, enabling smartphone-based identity proof via digital documents.

## Facts Content
**Launch Date**: July 7, 2025
**Service**: Eesti äpp (Estonia App) - New identity verification feature
**Functionality**: Digital identity verification via smartphone

**Technical Capabilities**:
- Present ID card digital data via smartphone
- Present passport digital data via smartphone
- Direct submission to service providers
- No physical document required

**Implementation Model**:
- Voluntary adoption by service providers
- Voluntary use by citizens
- Gradual rollout with service provider cooperation
- Phased implementation strategy

**Stakeholders**: Information System Authority (RIA) and Justice Ministry

**Notes**:
- Original language: Estonian
- Pre-announcement of major digital ID feature
- Voluntary nature emphasizes user choice
- Complements existing physical ID infrastructure
