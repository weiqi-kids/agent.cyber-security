# January 2023 cyber weather published with new format

## Summary
NCSC-FI revamped cyber weather reports for 2023 with updated look and new content. The reports target organizations and complement weekly reviews with monthly event summaries.

## Key Details
- **Change**: Revamped format and appearance
- **New Content**: Additional information added
- **Target Audience**: Organizations
- **Purpose**: Concise, easy-to-understand cyber event reporting
- **Frequency**: Monthly, complementing weekly reviews

## Context
This format update enhances NCSC-FI's threat intelligence communication strategy through more accessible monthly summaries.

## Notes
- Communication improvement initiative
- Enhances existing weekly review system
- Confidence: high
