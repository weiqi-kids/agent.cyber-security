# New ID Card Client Card Functionality Requires IT System Development

## Summary
Estonia's new ID cards from IDEMIA with new chip platform require service providers to implement IT system updates for electronic use and client card functionality.

## Facts Content
**Effective Date**: July 2025 (beginning)
**Card Manufacturer**: IDEMIA
**Change**: New chip platform for Estonian ID cards

**Technical Requirements**:
- Service providers must perform IT system development
- Updates needed for:
  - Electronic authentication
  - Client card functionality
  - Backend system compatibility

**Stakeholders Affected**:
- Service providers offering ID card authentication
- Organizations using ID card client card features
- IT system developers and integrators

**Official Announcement**: Information System Authority (RIA) of Estonia

**Notes**:
- Original language: Estonian
- Impacts e-government services ecosystem
- Transition period for system updates required
- Related to Estonia's national digital identity infrastructure
