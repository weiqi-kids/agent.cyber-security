## Summary
Starting July 7, 2025, Eesti app adds new function allowing users to verify identity directly via smartphone by presenting digital ID card or passport data. Voluntary solution with gradual rollout.

## Description
From July 7, 2025, a new function will be added to the Eesti app allowing users to verify their identity directly via smartphone by presenting digital ID card or passport data to service providers. The solution's use is voluntary for both service providers and users, with implementation happening gradually in cooperation with service providers.

## Technical Details
- **Launch Date**: July 7, 2025
- **Feature**: Digital identity verification
- **Data Sources**: ID card, passport
- **Adoption**: Voluntary, gradual rollout
