## 摘要

Estonia's State Information System Authority (RIA) is testing audio-based emergency alert notifications via the Eesti App and "Ole valmis!" (Be Ready!) mobile applications on March 16, 2026, in preparation for a national emergency alert system test on March 18, 2026.

## 事實內容

The State Information System Authority (RIA), in cooperation with the Rescue Board (Päästeamet) and the Women's Home Guard (Naiskodukaitse), is conducting audio-based test notifications through the Eesti äpp and "Ole valmis!" mobile applications on Monday, March 16, 2026, between 10:00–16:00.

The testing is necessary to verify that the developed alert features are functioning properly and to prepare for the nationwide emergency alert system test scheduled for March 18, 2026. This marks the first time the Eesti App is testing audio-based (sound-enabled) emergency alert delivery.

Original language: Estonian.
