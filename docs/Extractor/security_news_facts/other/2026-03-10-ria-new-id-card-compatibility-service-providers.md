## 摘要

The Estonian Information System Authority (RIA) clarifies that e-service providers must ensure their systems are compatible with new ID cards issued since November 17, 2025. Users experiencing issues should first contact the service provider.

## 事實內容

- New Estonian ID cards have been issued since November 17, 2025 with updated technical specifications
- E-service providers are responsible for ensuring their systems and software are compatible with the new card's technical solutions
- If a user experiences errors when using the new ID card with an e-service, they should first contact the service provider — not RIA directly
- The service provider can analyze the problem in detail and involve RIA if necessary
- RIA emphasizes that compatibility responsibility lies with individual e-service operators

## 受影響系統

- Estonian e-government services using ID card authentication
- DigiDoc4 application
- Web eID solution
- Third-party e-services relying on Estonian ID card infrastructure
