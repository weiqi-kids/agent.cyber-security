## Summary
Estonian Information System Authority created web-based Estonian Information Security Standard (E-ITS) support tool to help organizations systematically assess and develop their information security level.

## Description
The Estonian Information System Authority (RIA) created a web-based support tool for the Estonian Information Security Standard (E-ITS) that helps organizations systematically assess and develop their information security level. The tool simplifies implementation of the E-ITS standard by providing structured guidance and assessment capabilities.
