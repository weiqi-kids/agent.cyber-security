## 摘要

Following the Smart-ID+ upgrade introduced in Estonia's national authentication service on February 26, 2026, some national mobile applications may experience Smart-ID login errors due to technical compatibility issues.

## 事實內容

The Estonian Information System Authority (RIA) announced that following the introduction of the Smart-ID+ upgrade in the national authentication service (riigi autentimisteenus) on February 26, 2026, some national mobile applications may experience errors when logging in via Smart-ID. The errors are related to technical compatibility between mobile applications and the new Smart-ID+ solution in the national authentication service. RIA stated that work is being done to resolve the compatibility issues. This is a technical service disruption, not a security incident.

## 受影響系統

- Smart-ID authentication
- National authentication service (riigi autentimisteenus)
- National mobile applications using Smart-ID login
