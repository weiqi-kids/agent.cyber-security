## Summary
RIA calls for updating device software and vigilance before elections to ensure secure e-voting, warning of scams impersonating election commission workers seeking PIN codes.

## Factual Content
Before elections, RIA calls for updating device software and being attentive to ensure a secure journey for e-votes to the ballot box. There are scam schemes where fraudsters present themselves as election commission workers and try to extract PIN codes.

**Security Recommendations:**
- Update device software before voting
- Be vigilant against scams
- Warning: Fraudsters impersonating election officials
- Target: PIN code theft
- Context: E-voting security
