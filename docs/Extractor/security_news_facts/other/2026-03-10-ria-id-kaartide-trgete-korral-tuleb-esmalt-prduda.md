# RIA: For ID Card Errors, Contact Service Provider First (Estonia)

## 摘要
愛沙尼亞 RIA 說明新版 ID 卡相容性問題，要求服務提供商先確認系統相容性，再聯繫 RIA。

## 事實內容
愛沙尼亞資訊系統局（RIA）說明，自 2025 年 11 月 17 日起發行的新版 ID 卡，服務提供商需確保其系統和軟體與新卡的技術解決方案相容。若某些電子服務在使用新 ID 卡時出現錯誤，使用者應首先聯繫服務提供商，而非 RIA，以便服務提供商能更新其系統。

- 原始語言：愛沙尼亞語

## 受影響系統
- 愛沙尼亞新版 ID 卡（2025 年 11 月後發行）
- 使用 ID 卡認證的電子服務
