## Summary
Estonia's Rescue Board announced an emergency alert test for December 4, 2025, between 10:00-16:00, sending multiple test notifications through Eesti app and Ole valmis! app.

## Description
The Estonian Rescue Board, in cooperation with the Estonian Information System Authority (RIA) and the Women's Voluntary Defence Organization, will send test notifications through the Eesti app and "Ole valmis!" mobile application on Thursday, December 4, 2025, between 10:00-16:00.

Users may receive multiple test notifications during the testing period. The test aims to verify the apps' functionality as part of the national emergency alert system and prepare for the nationwide emergency alert system test scheduled for December 10, 2025.

## Technical Details
- **Test Date**: December 4, 2025
- **Test Window**: 10:00-16:00
- **Apps Tested**: Eesti app, Ole valmis! app
- **Expected Notifications**: Multiple test messages
- **Purpose**: Verify app functionality, prepare for December 10 nationwide test
- **Partners**: RIA, Women's Voluntary Defence Organization
