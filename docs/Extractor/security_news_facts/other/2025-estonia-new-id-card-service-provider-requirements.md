## Summary
Estonian Information System Authority reminds service providers that new chip platform ID cards issued by IDEMIA from early July require IT system development for electronic use or client card functionality.

## Description
The Estonian Information System Authority (RIA) reminds that from early July, Estonian card producer IDEMIA issues new chip platform ID cards. Service providers must make IT system developments to enable electronic use of these cards or client card functionality.

This represents a technical transition requiring proactive preparation by all service providers relying on ID card authentication.

## Technical Details
- **Start Date**: Early July 2025
- **Producer**: IDEMIA (Estonian card producer)
- **Change**: New chip platform
- **Requirement**: IT system development for service providers
- **Affected Functionality**: Electronic use, client card features
