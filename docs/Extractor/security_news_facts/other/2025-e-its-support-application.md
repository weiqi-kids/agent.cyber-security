## Summary
RIA creates web-based E-ITS support application helping organizations systematically assess and develop their information security level.

## Factual Content
The Information System Authority (RIA) has created a web-based Estonian Information Security Standard (E-ITS) support application that helps organizations systematically assess and develop their information security level.

**Application Features:**
- Platform: Web-based
- Purpose: E-ITS implementation support
- Functionality: Systematic assessment and development
- Target: Organizations implementing E-ITS
- Benefit: Simplified standard adoption
