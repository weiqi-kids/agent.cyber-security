## 摘要

NUKIB issued a recommendation advising Czech users to exercise caution when downloading and using applications that have suddenly gained popularity, emphasizing that users should only install from authorized stores (AppStore, Google Play) and carefully review requested permissions.

## 事實內容

- NUKIB advises users to be cautious with applications that gain sudden popularity
- Recommendations include only downloading apps from authorized stores: AppStore or Google Play
- Users should carefully monitor which device functions and data they grant access to
- The advisory follows observations of risky behaviors when users rush to adopt trending apps without security scrutiny
- The guidance applies to both personal and professional device usage

## 受影響系統

- Mobile devices (iOS and Android)
- Personal and enterprise mobile applications
