## 摘要

Microsoft ended support for Windows 7, Windows Server 2008, and R2 on January 14, 2020.

## 事實內容

Support for several Microsoft products ended on January 14, 2020, including Windows 7 operating system, Windows Server 2008, and its R2 version. Termination means Microsoft no longer provides technical support or software and security updates except certain exceptions. After support ends, operating systems are more vulnerable to data breaches and malicious activities. NCSC-FI recommends quickly updating or isolating outdated systems from public networks.

## 受影響系統

- Windows 7
- Windows Server 2008
- Windows Server 2008 R2
