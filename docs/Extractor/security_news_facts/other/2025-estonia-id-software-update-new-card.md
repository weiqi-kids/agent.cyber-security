## Summary
From early July 2025, IDEMIA issues new platform ID cards. Users receiving cards after early July must update ID software to version 25.5 (macOS/Ubuntu) or 25.6 (Windows) for electronic use like authentication and digital signatures.

## Description
Starting early July 2025, current Estonian card producer IDEMIA issues new platform ID cards. Users who received their ID cards after early July must update ID software for electronic use including authentication and digital signatures. Required versions are 25.5 for macOS and Ubuntu, and 25.6 for Windows.

## Technical Details
- **Start Date**: Early July 2025
- **Producer**: IDEMIA
- **Change**: New ID card platform
- **Required Versions**: 25.5 (macOS, Ubuntu), 25.6 (Windows)
- **Affected Functionality**: Authentication, digital signatures
- **Applies To**: Cards received after early July 2025
