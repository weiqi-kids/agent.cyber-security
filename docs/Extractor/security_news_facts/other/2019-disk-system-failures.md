## 摘要

RAID disk system malfunctions resulted in data loss despite fault tolerance.

## 事實內容

NCSC-FI became aware of several IT system malfunctions in recent weeks that resulted in data loss despite the fault tolerance (RAID) of disk systems. This highlights that even redundant storage systems can fail, emphasizing the need for proper backup strategies.

## 受影響系統

- RAID disk systems
- IT storage infrastructure
