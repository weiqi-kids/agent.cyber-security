## Summary
Eesti app users can now verify identity at Agricultural Registers and Information Board (PRIA) and Estonian Unemployment Insurance Fund service points using smartphone-based ID card or passport data submission.

## Description
Eesti app users can now prove their identity at the Agricultural Registers and Information Board (PRIA) and Estonian Unemployment Insurance Fund service points, in addition to existing service providers. Users can submit ID card or passport data conveniently and securely directly via smartphone.

This expansion of the Eesti app's identity verification functionality increases the convenience and security of accessing government services without physical document presentation.

## Technical Details
- **App**: Eesti app
- **New Service Points**: PRIA, Estonian Unemployment Insurance Fund
- **Feature**: Digital identity verification via smartphone
- **Accepted Documents**: ID card data, passport data
- **Benefits**: Convenience, security
