## 摘要

Estonia to test EE-ALARM emergency alert system on December 10, 15:00-15:10, including siren activation, mobile app notifications, and ERR channel messages.

## 事實內容

The Rescue Board announced that on Wednesday, December 10, 2025, it will test the comprehensive emergency alert system EE-ALARM in cooperation with partners.

Test schedule:
- Date: December 10, 2025
- Time: 15:00-15:10
- Advanced SMS notification: Morning of December 10

Test components:
- Siren network activation with real emergency signal
- Notifications via Eesti app
- Notifications via "Ole valmis!" mobile app
- Emergency information on ERR channels
- SMS used only for advance notification this time

All mobile phones in Estonia will receive advance SMS notifications in the morning about the afternoon test, particularly regarding the siren activation.

## 受影響系統

- EE-ALARM national emergency system
- National siren network
- Eesti app
- Ole valmis! mobile app
- SMS broadcasting system
- ERR broadcasting channels
