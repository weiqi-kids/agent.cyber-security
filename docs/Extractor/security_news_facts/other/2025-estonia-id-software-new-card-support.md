## Summary
Estonian Information System Authority released ID software version 25.10 supporting the new ID card launching in mid-November, with changes to card appearance, chip technology, and software requiring updates.

## Description
The Estonian Information System Authority (RIA) released ID software version 25.10 to support the new ID card being introduced in the second half of November 2025. The new ID card brings changes to card appearance, chip technology, and software, requiring ID software updates for electronic use.

Users must update their ID software to version 25.10 to use the new ID cards electronically. The update is necessary due to technical changes in the card's chip and software architecture.
