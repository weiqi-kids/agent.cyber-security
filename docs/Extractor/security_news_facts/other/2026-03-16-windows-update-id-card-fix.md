## 摘要

A Windows update released on March 10 fixes errors with new Estonian ID cards issued since November 2025, where DigiDoc4 failed to recognise the card.

## 事實內容

The Estonian Information System Authority (RIA) announced that the Windows update published on March 10, 2026, resolves errors that occurred with new ID cards. The new ID cards, issued since November 17, 2025, caused issues where the DigiDoc4 application might not detect the card. RIA recommends downloading and installing the latest Windows software update to ensure error-free ID card usage.

## 受影響系統

- Microsoft Windows (all affected versions)
- DigiDoc4 application
- Estonian ID cards (issued from November 17, 2025)
- Estonian e-services using ID card authentication
