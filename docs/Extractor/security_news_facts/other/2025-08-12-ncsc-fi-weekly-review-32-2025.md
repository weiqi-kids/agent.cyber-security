## 摘要

NCSC-FI 第32週週報：M365帳號入侵與網路釣魚，Citrix漏洞資料洩露現況，及新惡意軟體週報發布。

## 事實內容

- Organisations' Microsoft 365 accounts have been breached; phishing messages are actively used as an attack vector.
- Citrix vulnerability continues to cause data breaches; NCSC-FI provided situational update on affected organisations.
- NCSC-FI launched a new weekly malware review providing current information on active malware threats.
- Reminder issued regarding children's information security skills as the school year begins.

## 受影響系統

- Microsoft 365 (M365)
- Citrix products (vulnerability-related data breaches)
