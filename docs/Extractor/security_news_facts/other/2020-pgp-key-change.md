## 摘要

NCSC-FI CERT function updates PGP keys; new keys available on website and key servers.

## 事實內容

The NCSC-FI Incident Response, NCSC-FI Advisory Signing Key, and NCSC-FI Newsfeed Signing Key in the CERT function are being changed. New keys are available on the Centre's website and on public key servers. Organizations using NCSC-FI's encrypted communications should update to the new keys.

## 受影響系統

- Organizations using NCSC-FI PGP encrypted communications
