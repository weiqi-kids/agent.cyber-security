## Summary
New ID cards launch November 14, 2025, with production moving from IDEMIA to Thales. Service providers must update IT systems before this date or new ID cards won't function electronically.

## Description
New ID cards will be introduced on November 14, 2025, with production shifting from IDEMIA to Thales. The Estonian Information System Authority (RIA) reminds service providers that their IT systems must be updated before this date. Without necessary updates, electronic use of new ID cards in service provider systems will not be possible, and customer card functionality will not work.

This is a critical deadline for all organizations providing services that rely on Estonian ID card authentication. Failure to update systems will result in service disruptions for users with new ID cards.

## Technical Details
- **Launch Date**: November 14, 2025
- **New Producer**: Thales (replacing IDEMIA)
- **Requirement**: Service provider IT system updates mandatory
- **Deadline**: Before November 14, 2025
- **Impact**: Electronic ID card use and customer card functionality will fail without updates
- **Authority**: Estonian Information System Authority (RIA)
