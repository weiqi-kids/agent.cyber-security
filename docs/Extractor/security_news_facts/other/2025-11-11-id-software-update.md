## Summary
RIA releases ID software version 25.10 supporting new ID card launching in second half of November with changes to appearance, chip technology, and software.

## Factual Content
The Information System Authority (RIA) released a new version of ID software 25.10, which supports the new ID card to be introduced in the second half of November. The new ID card brings changes to both the card's appearance, chip technology, and its software, which is why updating ID software is necessary for its electronic use.

**Key Details:**
- New software version: 25.10
- New ID card launch: Second half of November 2025
- Changes: Card appearance, chip technology, software
- Action required: Update ID software for electronic functionality
- Importance: Mandatory for using new cards electronically
