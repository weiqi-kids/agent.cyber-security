## 摘要

Estonia's RIA released ID software version 26.4 on May 13, 2026 as a regular update for reliability, security, and user experience. RIA also announced that Windows 10 support in the ID software will end this autumn.

## 事實內容

- **Organization**: Riigi Infosüsteemi Amet (RIA)
- **Release date**: May 13, 2026
- **New version**: ID software version 26.4
- **Update type**: Regular update — aims to ensure software reliability, security, and improved user experience
- **Important notice**: Windows 10 support in the ID software will be discontinued starting autumn 2026
- **Impact**: Users running Windows 10 will need to upgrade their OS or find alternative means to use Estonian ID software

## 受影響系統

- Estonian ID software (version 26.4)
- Windows 10 users in Estonia
