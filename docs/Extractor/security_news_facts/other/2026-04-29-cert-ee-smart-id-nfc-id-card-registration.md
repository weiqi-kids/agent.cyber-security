## 摘要

From April 29, 2026, Smart-ID accounts can be registered using an ID card and NFC-enabled smartphone, eliminating the need for a computer, card reader, or browser. This also reduces fraud risk compared to the previous card-reader-based method.

## 事實內容

- **Effective date**: April 29, 2026
- **Change**: Smart-ID account registration via ID card + NFC-enabled smartphone is now available
- **Eliminates need for**: Computer, separate card reader, internet browser
- **Replaces**: Previous card-reader-based registration method
- **Security benefit**: New method reduces fraud risk associated with the old registration process
- **Impact**: Simplified and more secure onboarding for Smart-ID, Estonia's digital authentication system

## 受影響系統

- Smart-ID authentication platform (Estonia)
- Estonian digital identity infrastructure
- NFC-enabled smartphones
