## Summary
Estonia's Rescue Board announced a nationwide emergency alert system test for December 10, 2025, between 15:00-15:10, including siren activation, Eesti app notifications, and broadcast alerts.

## Description
On December 10, 2025, the Estonian Rescue Board will test the EE-ALARM emergency alert system with partners between 15:00-15:10. The test includes activating the siren network with a real alarm signal, distributing information via the Eesti app and "Ole valmis!" mobile application, and broadcasting on ERR channels.

SMS will be used only for advance notification during this test. In the morning, all mobile phones in Estonia will receive SMS messages informing about the afternoon test, particularly regarding the siren activation.

This is a pre-announcement for a planned system test to ensure the emergency alert infrastructure functions properly.
