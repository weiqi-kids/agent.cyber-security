## 4. 頁面規劃

### 4.1 首頁優化

| 項目 | 內容 |
|------|------|
| 頁面 URL | / |
| 類型 | 修改 |
| 所屬階段 | Phase 2 |
| 優先級 | P1 |

#### 頁面策略

| 項目 | 說明 |
|------|------|
| 頁面目標 | 快速導引使用者找到最新報告 |
| 目標受眾 | 首次訪客 + 定期回訪者 |
| 關鍵訊息 | 1. 最新報告連結 / 2. 更新時間 / 3. 資料來源數量 |
| 主要 CTA | 「查看本週威脅態勢報告」 |
| 次要 CTA | 「訂閱 RSS」 |

#### 內容大綱

```
1. Hero 區塊
   - 標題 + 一句話描述
   - 「查看最新報告」按鈕（醒目）

2. 系統概覽
   - 四個資料層卡片（維持現有）
   - 加入「最後更新時間」更突顯

3. 活躍利用漏洞
   - 維持現有，加入「查看全部」連結

4. 最新報告
   - 威脅態勢 + 防禦建議 雙欄呈現
   - 加入 RSS 訂閱圖示
```

## 6. 風險與依賴

### 風險

| 風險 | 影響 | 緩解措施 |
|------|------|----------|
| TBT 根因難定位 | 可能需要較多時間排查 | 使用 Lighthouse 詳細報告定位 |
| 搜尋索引太大 | 可能影響載入速度 | 只索引標題和摘要 |
| Just the Docs 升級 | 可能影響現有樣式 | 先在測試分支驗證 |

### 依賴

| 依賴項目 | 影響範圍 | 處理方式 |
|----------|----------|----------|
| Jekyll feed 插件 | RSS 功能 | 確認 GitHub Pages 支援 |
| Lunr.js | 搜尋功能 | 確認與 Just the Docs 相容 |
