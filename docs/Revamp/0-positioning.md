# 品牌定位文件

> 產出日期：2026-02-19
> 網站 URL：https://security.weiqi.kids/

---

## 1. 核心資訊

| 項目 | 內容 |
|------|------|
| **網站名稱** | 資安威脅情報中心 |
| **一句話描述** | 自動化收集、萃取、分析全球資安威脅情報的開源情報平台 |
| **核心價值主張** | 透過 AI 自動化將分散的資安情報轉化為可行動的防禦建議，讓資安人員專注於決策而非資料收集 |

---

## 2. 目標受眾

### 主要受眾 (Primary)

| 項目 | 描述 |
|------|------|
| **是誰** | 企業資安人員、SOC 分析師、IT 管理者 |
| **目標/需求** | 快速掌握最新威脅態勢，決定修補優先順序，向上級報告資安狀況 |
| **痛點** | 情報來源分散（CISA、各國 CERT、CVE 資料庫）、資訊量龐大難以消化、缺乏時間整理週報 |
| **使用場景** | 每週例行檢視威脅態勢、漏洞爆發時快速評估影響、準備資安月報/週報 |

### 次要受眾 (Secondary)

| 項目 | 描述 |
|------|------|
| **是誰** | 資安研究人員、技術部落客、資安學習者 |
| **目標/需求** | 追蹤最新漏洞趨勢、了解攻擊手法演變、獲取研究素材 |
| **痛點** | 需要花大量時間訂閱和閱讀各種來源 |
| **使用場景** | 撰寫研究報告、準備演講素材、學習資安知識 |

---

## 3. 差異化定位

| 項目 | 內容 |
|------|------|
| **與競品的差異** | 完全開源、中文介面、AI 自動萃取重點、聚焦「可行動」的防禦建議而非單純列舉 |
| **獨特優勢** | 跨來源整合（47,000+ 筆資料）、每週自動產出結構化報告、標註「正被實際利用」的漏洞 |
| **不做什麼** | 不做付費訂閱、不做即時告警推播、不做企業客製化服務、不做漏洞掃描工具 |
