## 頁面規格書

### 1. 首頁 CTA 優化

#### 基本資訊

| 項目 | 內容 |
|------|------|
| 頁面 URL | / |
| 頁面類型 | 首頁 |
| 所屬階段 | Phase 2 |
| 優先級 | P1 (S5) |
| 來源 | 策略計劃 4.1 |

#### 1.1 頁面目標

**主要目標**：快速導引使用者找到最新報告

**次要目標**：
1. 傳達網站核心價值
2. 建立專業可信印象
3. 引導訂閱 RSS

**成功指標**

| 指標 | 目標值 | 測量方式 |
|------|--------|----------|
| CTA 點擊率 | > 10% | GA 事件追蹤 [假設] |
| 跳出率下降 | -5% | GA [假設] |

#### 1.2 內容結構

##### Hero 區塊（新增）

| 元素 | 規格 | 範例 |
|------|------|------|
| 標題 | 網站名稱，粗體 | 資安威脅情報中心 |
| 副標題 | 一句話描述，≤30 字 | 自動化收集、萃取全球資安威脅情報 |
| CTA 按鈕 | 醒目按鈕，主色調 | 「查看本週威脅報告」 |
| CTA 連結 | 最新週報 URL | /docs/Narrator/threat_landscape/2026-W08/ |

**文案方向**：
- 簡潔有力，不超過 30 字
- 動作導向（「查看」而非「了解」）
- 按鈕文字 ≤ 10 字

##### 系統概覽區塊（修改）

| 元素 | 現況 | 修改 |
|------|------|------|
| 更新時間 | 小字 | 加粗、位置提前 |
| 資料筆數 | 有 | 維持 |
| 新增 | — | 加入「上次更新」時間戳 |

##### 最新報告區塊（修改）

| 元素 | 規格 |
|------|------|
| 標題 | 「最新報告」 |
| 排版 | 雙欄：威脅態勢 / 防禦建議 |
| 連結 | 各自連到最新週報 |
| RSS 圖示 | 右上角，連到 /feed.xml |

#### 1.3 CTA 規格

**主要 CTA**

| 項目 | 規格 |
|------|------|
| 文案 | 查看本週威脅報告 |
| 位置 | Hero 區塊中央 |
| 連結目標 | 最新威脅態勢週報 |
| 樣式 | 按鈕、主色調、hover 效果 |

**次要 CTA**

| 項目 | 規格 |
|------|------|
| 文案 | 訂閱 RSS |
| 位置 | 最新報告區塊右上 |
| 連結目標 | /feed.xml |
| 樣式 | RSS 圖示 + 文字連結 |

#### 1.4 SEO 規格

| 項目 | 規格 |
|------|------|
| Title | 資安威脅情報中心 - 自動化威脅情報分析 |
| Meta Description | 免費開源的資安威脅情報平台，每週自動萃取全球資安情報，提供可行動的防禦建議。 |
| H1 | 資安威脅情報中心 |

### 2. 站內搜尋功能

#### 基本資訊

| 項目 | 內容 |
|------|------|
| 功能位置 | 全站頁首 + /search/ 頁面 |
| 所屬階段 | Phase 2 |
| 優先級 | P1 (S3) |

#### 2.1 功能目標

**主要目標**：讓使用者快速找到特定 CVE 或歷史報告

**成功指標**

| 指標 | 目標值 | 測量方式 |
|------|--------|----------|
| 搜尋使用率 | > 5% 訪客使用 | GA 事件 [假設] |
| 搜尋成功率 | > 80% 有結果 | 監測 [假設] |

#### 2.2 功能規格

##### 搜尋框

| 元素 | 規格 |
|------|------|
| 位置 | 頁首導航列右側 |
| placeholder | 「搜尋 CVE 編號或關鍵字...」 |
| 寬度 | 200px，focus 時展開到 300px |
| 快捷鍵 | Ctrl+K 或 / |

##### 搜尋結果

| 元素 | 規格 |
|------|------|
| 呈現方式 | 新頁面 /search/?q=XXX |
| 結果排序 | 相關性優先，日期次之 |
| 結果格式 | 標題 + 摘要（150 字）+ 日期 |
| 高亮 | 關鍵字高亮顯示 |
| 無結果 | 「找不到符合的內容，請嘗試其他關鍵字」 |

##### 技術方案

| 項目 | 規格 |
|------|------|
| 方案 | Just the Docs 內建搜尋 或 Lunr.js |
| 索引範圍 | 標題、內文前 500 字 |
| 索引更新 | 每次 build 時重建 |

### 3. RSS Feed

#### 基本資訊

| 項目 | 內容 |
|------|------|
| 頁面 URL | /feed.xml |
| 所屬階段 | Phase 2 |
| 優先級 | P1 (S4) |

#### 3.1 功能目標

**主要目標**：讓使用者可以訂閱週報更新

**成功指標**

| 指標 | 目標值 | 測量方式 |
|------|--------|----------|
| RSS 訂閱數 | 追蹤請求數 | Server logs [假設] |

#### 3.2 Feed 規格

| 項目 | 規格 |
|------|------|
| 格式 | Atom 或 RSS 2.0 |
| 標題 | 資安威脅情報中心 - 最新報告 |
| 描述 | 每週自動更新的資安威脅態勢分析與防禦建議 |
| 項目來源 | docs/Narrator/ 下的週報 |
| 項目數量 | 最新 20 篇 |

##### 每個 Feed Item

| 元素 | 來源 |
|------|------|
| title | 週報標題 |
| link | 週報 URL |
| pubDate | 週報發布日期 |
| description | 週報前 300 字摘要 |
| category | threat_landscape 或 defense_recommendations |

##### 技術方案

| 項目 | 規格 |
|------|------|
| 方案 | Jekyll Feed 插件 |
| 設定 | _config.yml 加入 feed 設定 |

### 4. ATT&CK 映射（內容標籤）

#### 基本資訊

| 項目 | 內容 |
|------|------|
| 適用位置 | 威脅態勢週報內文 |
| 所屬階段 | Phase 2 |
| 優先級 | P1 (S6) |

#### 4.1 標籤規格

| 項目 | 規格 |
|------|------|
| 標籤格式 | `[TTP: TXXXX.XXX]` 或 Badge |
| 連結目標 | MITRE ATT&CK 官網對應頁面 |
| 適用時機 | 當報告中提到具體攻擊手法時 |

##### 範例

```markdown
攻擊者使用釣魚郵件 [TTP: T1566] 作為初始存取手段...
```

或使用 Badge 樣式：

```html
<span class="ttp-badge">T1566</span>
```
